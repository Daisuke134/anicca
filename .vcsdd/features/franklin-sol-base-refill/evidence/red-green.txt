## relay.link research (search-first, cited before implementing -- persisted here per project
## rule, not just in chat)

- https://docs.relay.link/references/api/get-quote (the exact `/quote` endpoint this codebase's
  RELAY_API constant targets) -- own documented example: `originCurrency`/`destinationCurrency`
  "0x0000000000000000000000000000000000000000" swaps Base ETH (chain 8453) for Optimism ETH
  (chain 10). Confirms the all-zero address is relay.link's sentinel for a chain's native
  currency (not USDC-specific).
- https://docs.relay.link/references/api/get-quote-v2 -- identical request/response shape,
  confirms `details.currencyIn`/`currencyOut.amount` is the raw base-unit string (wei for native
  ETH), sibling to `.amountUsd` this feature's existing `_extract_quote_usd` already parses.
- https://docs.relay.link/features/gas-top-up -- confirms "Gas Top-Up" (`topupGas`) is a
  DIFFERENT feature (adds native gas alongside a non-native bridged token; explicitly
  incompatible with bridging TO the native token itself) -- NOT used by this mode, which does a
  plain USDC-in/native-ETH-out swap via the existing quote/poll/sign/submit flow.
