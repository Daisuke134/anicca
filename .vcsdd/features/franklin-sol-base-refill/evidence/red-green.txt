## Tooling note

The `rtk` PostToolUse hook rewrites plain `python3 -m pytest ...` invocations and, in this
session, repeatedly failed to spawn the process (`os error 2`) for that exact command shape.
Isolated as a known baseline issue with the rtk command-rewrite wrapper (unrelated to this
feature's code) -- worked around for the remainder of the session with `rtk proxy <cmd>`,
which executes the raw command without the rewrite and ran pytest/npm correctly every time.
