## Gotcha

- README の config 例 (`"scheme":"...","chains":["..."]`) は実 Rust schema とズレている。真実は `crates/x402-types/src/scheme/mod.rs::SchemeConfig{id, chains: ChainIdPattern}` + `crates/x402-types/src/config.rs::Config{chains: TChainsConfig}`（CAIP-2 key）。ソースを正とした。
- `depositETH` の gas 見積もりが低いと ~94% gas 使用で revert（1回踏んだ、`gas: 900000n` で解消）。
- USDC EIP-712 domain は on-chain `name()/version()` 呼び出しで実測（"USDC"/"2"）、決め打ちしない。
- CapSolver は hCaptcha を deprecated 済み（`ERROR_INVALID_TASK_DATA`）→ hCaptcha は自力視覚判定、reCAPTCHA Enterprise は CapSolver `ReCaptchaV2EnterpriseTaskProxyLess` + client callback 直接 invoke（DOM textarea 書き込みだけでは React state に反映されない）。
