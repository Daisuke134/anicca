# Living home Rive asset

`living_home.riv` is an intentionally empty placeholder, not a valid Rive export.
This environment has no Rive editor/exporter or Apple build tools; downloading
an upstream sample through the shell also timed out. The existing theme remains
visible until a valid export replaces this file. Rive animation is not yet visible.

Export a self-contained, transparent `.riv` with this contract:

- Artboard: `LivingHome` (portrait; softly moving translucent shapes).
- State machine: `Living`.
- Entry state: `Ambient`, an endlessly looping slow drift/breathing animation.
- Trigger input: `WordChanged`.
- On the trigger, play a brief (about 0.6 seconds) glow/ripple transition and
  return to `Ambient`; allow subsequent triggers while a transition is playing.
- Embed all assets; CDN loading is disabled.

The app target's synchronized `aniccaios` folder includes the Swift view and
copies this resource into the bundle. The loader resolves `living_home` by name,
validates the artboard/state machine/trigger, and falls back to the theme if
loading fails. Playback pauses when inactive, offscreen, or Reduce Motion is on.

Recording: launch with `-aniccaRecordingMode` (optionally with `-uiTesting`).
Words advance after 3 seconds of idle time while active, with multiple cards
and no sheet open. Without the recording flag, the existing 8-second production
interval and disabled UI-test auto-advance remain unchanged.

Before shipping: replace the placeholder, resolve SPM in Xcode, build/run on iOS,
and check ambient playback plus manual/automatic/notification word transitions.
The `RiveRuntime` package is pinned to 6.12.2; the workspace lockfile must be
regenerated by Xcode after resolving the new dependency.
