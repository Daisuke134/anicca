# 現金化ガイド

あなたのアニッチャは **Base 上の USDC** で稼ぐ。お金はあなたとアニッチャの間を行き来する。入れるのがシード、受け取るのが配当。国を選んで。

## 🇺🇸 アメリカ：Base で直接

どちらも簡単。取引所を経由せず、数秒で着金、毎日でもできる。

- **あなた → アニッチャ（シード）:** 自分のウォレット（MetaMask か Coinbase）から、アニッチャの Base ウォレットへ **USDC（Base）** を送るだけ。
- **アニッチャ → あなた（配当）:** アニッチャがあなたの Base ウォレットへ **USDC（Base）** を直接送る。

これでループは完結する。1 ネットワーク、1 トークン。

## 🇯🇵 日本：Binance、PayPay、Solana 経由

日本は銀行から Base へ直接乗る綺麗な道がないので、Binance Japan と Solana を経由する。（SBI VC Trade は銀行着金まで約 1 日かかって遅いので使わない。）

### あなた → アニッチャ（投資する）
1. **Binance Japan** に PayPay でチャージする。
2. Binance で **Solana（SOL）を買う**。
3. SOL を自分の **MetaMask**（Solana アドレス）へ **送る**。
4. [relay.link](https://relay.link) か Jupiter で SOL を **Base 上の USDC** に **スワップしてブリッジ** し、アニッチャの Base ウォレットへ送る。

### アニッチャ → あなた（受け取る）
1. アニッチャが **USDC か SOL** を、あなたの **Binance 入金アドレス** へ送る。
2. Binance で **売って** 日本円にする。
3. **PayPay に出金する。** Binance Japan アプリは PayPay 出金に対応している。

この道は毎日でも回せる。銀行の数日待ちがない。

## 正直なところ

完全に即時で human-in-loop ゼロなのは、Base 上のウォレット同士だけ。銀行や取引所や PayPay に触れる道は、一度だけ本人確認（KYC）した口座が要る。そこが人間のブリッジになる。一度作ってしまえば、あとは毎日回る。
