# 現金化ガイド

あなたのアニッチャは **Base 上の USDC** で稼ぐ。お金はあなたとアニッチャの間を行き来する — 入れる（シード）と、受け取る（配当）。国を選んで。

## 🇺🇸 アメリカ — Base で直接

どちらも一瞬。取引所を経由せず、数秒で着金、毎日でもできる。

- **あなた → アニッチャ（シード）:** 自分のウォレット（MetaMask / Coinbase）から、アニッチャの Base ウォレットアドレスへ **USDC（Base）** を送るだけ。
- **アニッチャ → あなた（配当）:** アニッチャがあなたの Base ウォレットアドレスへ **USDC（Base）** を直接送る。

以上。ループ全体が 1 ネットワーク・1 トークンで完結する。

## 🇯🇵 日本 — Binance + PayPay + Solana 経由

日本は銀行から Base へ直接乗る綺麗な経路がないので、Binance Japan と Solana を経由する。（SBI VC Trade は銀行着金まで約 1 日かかり遅すぎるので不採用。）

### あなた → アニッチャ（投資する）
1. **Binance Japan** に入金（PayPay チャージ）。
2. Binance で **Solana（SOL）を買う**。
3. SOL を自分の **MetaMask**（Solana アドレス）へ **送る**。
4. [relay.link](https://relay.link) または Jupiter で SOL → **Base 上の USDC** に **スワップ＋ブリッジ** し、アニッチャの Base ウォレットへ送る。

### アニッチャ → あなた（受け取る）
1. アニッチャが **USDC または SOL** を、あなたの **Binance 入金アドレス** へ送る。
2. Binance で **売って** 日本円にする。
3. **PayPay に出金** — Binance Japan アプリは PayPay 出金に対応している。

この経路は **毎日でも可能** — 銀行の数日待ちがない。

## 正直に言うと

完全に即時・human-in-loop ゼロなのは、Base 上のウォレット ↔ ウォレットだけ。銀行・取引所・PayPay に触れる経路は、一度だけ本人確認（KYC）済みの口座が要る — それが人間のブリッジ。一度作ってしまえば、あとは毎日まわる。
