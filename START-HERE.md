# Start here — Anicca

Anicca is an open company. Its mission is to end suffering. This repository is the public flagship: everything we can open lives here — product code, research, and evaluations. Credentials, raw operations records, and customer data are kept in a separate private repository and are never published here.

## The names

- **Company**: Anicca
- **Model**: **Manager** — understands how a person responds to a stimulus (a notification, a reply, a deliverable) and chooses the input that maximizes the response people actually want. It learns from measured stimulus → response data (post-training, not pre-training).
- **Eval**: **ManagerBench** — one benchmark: the ability of AI to make something people want. One case is always *situation → what the AI made (stimulus) → the person's measured response* (accepted, paid, rated, continued — never impressions).
- **Product**: **Anicca** — an affirmation and nudge app. Affirmation is the entry; the product is behavior intervention that reduces suffering. **Life Manager**, the system that runs client work with no human in the loop, also lives in this repository.
