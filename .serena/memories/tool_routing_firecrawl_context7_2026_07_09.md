# Tool routing preference

User requested:

- When searching the web, use Firecrawl CLI.
- For searching documents, use Context7 CLI.

Operational note:

- Prefer `/opt/homebrew/bin/firecrawl` for web search/research when available.
- Prefer Context7 CLI for documentation lookup when available; if no standalone `context7`
  command exists, check the local installation path or use the available Context7 MCP/CLI
  equivalent before falling back.
