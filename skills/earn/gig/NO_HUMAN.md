# NO-HUMAN — Coconala direct-owner loops

Daily operation is performed by the four launchd owners documented in `SLOT_CC.md`.
Each owner has its own lock, browser context lease, durable receipt, Telegram report, and fail-closed boundary.

Revenue is counted only from immutable verified payment receipts. Views, applications, inquiries, estimates,
dry runs, and unknown values are never treated as earnings. Storefront and Apply attribution remain separate;
missing linkage remains `unknown`.

`run.sh` and the shared earning-health registry are read-only observers. No shared gig-pass shell, tmux core,
legacy healthcheck, or legacy auditor is part of the runtime.
