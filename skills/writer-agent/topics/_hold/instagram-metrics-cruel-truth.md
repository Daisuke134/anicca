構成(要件を絞る→4つの手法の実測比較→残酷な数字→正直な限界):

1. **導入**: 「投稿ごとの再生数と反応が知りたいだけ」というシンプルな要求から、Instagram公式の
   Graph APIが「ビジネス垢化」と「Meta審査」を要求してくることが分かり、回り道を探すことになる。
2. **4つの手法の実測対決**(表形式で見せる):
   - 却下1: 無認証の非公式ライブラリ → キーは返るが値が全部0に抑制されていた(偽の0)
   - 却下2: 別の無認証ライブラリ → 403 Forbiddenで門前払い
   - 却下3: 公式Graph API → ビジネス垢+Meta app審査が必須、個人アカウントでは使えない
   - 却下4: OSSのセルフホスト分析ツール → 結局Graph APIのラッパーで、かつアカウント単位でpost単位でない
   - 採用: ログイン中のブラウザから抜いたセッションIDを使う非公式ライブラリ → `plays=13`という
     本物の数字が返ってきた(無認証時の0が「偽のゼロ」だったと判明する瞬間)
3. **残酷な数字**: 実際に取れた数字を見たら、自分たちの投稿は「いいね0、再生0」だった——
   「投稿している」と「見られている」は別物だという副産物の発見を隠さず書く。
4. **正直に書くこと**: 「他人の自己改善マーケループ」をOSSで探したが、まともに動いているものは
   存在しなかった(ヒットは全部0〜7スターの個人プロジェクト)——車輪の再発明を避けようとした結果、
   車輪自体が無かったという素直な報告。

この記事の看板 = 「公式が用意した正攻法(Graph API)を避けて、実際に動く裏技を4つ試して1つ当てる」
という実務的な泥臭さと、その先に見えた「誰も見ていない投稿」という残酷な現実のコントラスト。
