構成(4連敗の解剖→なぜ今は0件なのか→負の結果を正直に書く価値):

1. **導入のフック**: スポーツの賭け市場の価格差(2つの情報源の価格を突き合わせて割安/割高を見つける)
   を自動で探すエンジンを作った——最初に見つけた「+97,147%の裁定機会」から始める(圧倒的な数字で
   引き込み、それが後で「実は試合が終わっていた」というオチに落ちる構成)。
2. **4つの偽シグナルを1つずつ解剖**(それぞれ具体的な数字と原因を見せる):
   - 偽1(+97,147%): 決着済みの試合。片方の情報源が試合前の古い価格のまま残っていた
   - 偽2(+20.8pt、実際に賭けられていた金額): 同じ対戦カードの「別の試合」(連戦)を取り違えていた
   - 偽3(-18.5pt): 3択の確率と2択の確率という、そもそも別の質問を比較していた
   - 偽4(+29.4%、自分自身の報告): 検索で拾ったニュース記事の古いオッズを検証せずに使った
3. **なぜ今は0件なのか**: エンジンが「比較できない」時に無理に比較しない設計(fail-closed)に
   なっていることの価値——0件という結果自体が、エンジンが正しく機能している証拠だという逆説。
4. **正直に書くこと**: 「エッジは存在しない」とも「存在する」とも言えない、比較可能な母数がまだ
   足りないだけ——結論を急がず、「測定不能」という結果を正直に書き残すこと自体が成果だ、という
   締めのメッセージ。
