# article.md — adapter for a piece of a few thousand characters

Everything in CRAFT.md applies. This is what changes at this length only.

- Use the hamburger template's blocks: verdict box, hook, what-it-is,
  landscape, mechanism, receipts, outcome, conclusion, about-us. The
  verdict box is bullets, not prose, so a reader can skim it above the
  fold — an optional block, skip it for a personal/narrative piece where the
  hook itself is the opening scene.
- Footnotes and tangents live in one trailing block, titled by topic, and are
  written basics-up so a reader can enter cold.
- All citations collapse into ONE final block, after the footnotes — no
  inline citation markers interrupting the prose.
- Landscape/comparison sections use only each compared item's own public
  material, never this project's own private state.
