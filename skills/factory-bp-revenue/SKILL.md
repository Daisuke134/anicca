## 手順

### 1. BP検索（web_search + firecrawl）

x_search（Grokビルトインツール）で検索する:

```
x_search query="mobile app paywall conversion best practice 2026"
x_search query="indie app subscription pricing strategy"
x_search query="app onboarding trial optimization"
```

※ x_searchはGrok経由でXを検索し、引用URL付きの要約を返す。
※ web_searchは結果が長すぎてSlack Message failedになるため使わない。

### 2. 結果を保存

見つけたBPを以下に保存:
```
/Users/anicca/.openclaw/workspace/factory-evolution/revenue-bp-YYYY-MM-DD.md
```

フォーマット:
```markdown
# Revenue BP — YYYY-MM-DD

## Finding 1
Source: [タイトル] (URL)
Quote: 「原文コピー」
→ 適用先: [どのスキルのどの部分]

## Finding 2
...
```

### 3. スキル編集

見つけたBPに基づき、mobileapp-builder内の**正本ファイル**だけを差分編集する:
- パス: `/Users/anicca/.openclaw/skills/factory-bp-revenue/SKILL.md` と `/Users/anicca/.openclaw/workspace/factory-evolution/revenue-bp-YYYY-MM-DD.md`
- **テンプレート配下の `mobileapp-builder/CLAUDE.md` は編集しない**。テンプレート更新が必要なら `mobileapp-builder/SKILL.md` のみを対象にする
- **全編集にソース+URL+原文引用を付ける**
- 引用できない編集はしない
- **1回の apply_patch で複数ファイルを無理にまとめない**。差分が大きいときは file-by-file に分けて `edit` を使う
- `apply_patch failed` が出たら、同じパッチを再試行せず、対象ブロックを小さく分割して再編集する

### 4. git commit

```bash
cd /Users/anicca/anicca-project && git add -A && git commit -m "factory-bp-revenue: [日付] [改善内容の要約]"
```

### 5. Slack報告

**cron 実行では Slack を送らない。`openclaw message send` は絶対に呼ばない。**
結果は `workspace/factory-evolution/revenue-bp-YYYY-MM-DD.md` と skill の更新で完結させる。
手動で別途報告が必要な場合のみ、cron 外で短く送る。
