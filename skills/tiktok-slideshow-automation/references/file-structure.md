# File Structure

Use one working folder per post.

## Required files
- `reference.md` or `reference.json`, saved from the source post
- `prompts.json`, containing hook, caption, and generation prompts
- `slides.json`, containing the slide plan
- `caption.txt`, containing the final caption
- `hashtags.txt`, containing the final hashtag set
- `schedule.json`, containing platform, date, and time
- `output/slide_01.png` through `output/slide_06.png`
- `upload.json`, containing the Postiz upload result or draft payload

## Suggested folder layout
- `work/<post-name>/reference/`
- `work/<post-name>/planning/`
- `work/<post-name>/output/`
- `work/<post-name>/publish/`

## Rule
Keep the source reference, plan, and final upload record together so the whole post can be reproduced later.
