# Workflow

1. Inspect the reference article or post.
2. Extract the hook, payoff, CTA pattern, and slide count.
3. Decide whether the post is educational, emotional, or curiosity-driven.
4. Write an English-only slide outline.
5. Prepare the image set.
6. Generate slide images.
7. Save the prompt and schedule inputs.
8. Upload as Postiz draft.
9. Queue for the target time.

## Default slide structure
- Slide 1: hook
- Slides 2 to 4: proof, explanation, or steps
- Slide 5: payoff or key takeaway
- Slide 6: soft close, usually save/follow without a hard sell

## Timing
- English-only audience: schedule for US evening local time.
- If the niche is broad consumer content, prefer 7 pm to 10 pm local time.
- If the post is utility-first, prefer weekday evenings.
- If the post is curiosity-first, prefer late evening testing windows.

## Draft mode
Use draft mode when possible, then manually review before final publish.
