# Visual Flow

```text
Reference post
  ↓
Extract hook, structure, style
  ↓
Write English-only hook variants
  ↓
Choose image style and source images
  ↓
Build slides.json
  ↓
Generate 6 PNG slides
  ↓
Write caption.txt and hashtags.txt
  ↓
Write schedule.json
  ↓
Upload as Postiz draft
  ↓
Review manually
  ↓
Publish at audience evening peak
```

## Per-slide structure
```text
Slide 1: hook
Slide 2: problem or setup
Slide 3: first point
Slide 4: second point
Slide 5: payoff or proof
Slide 6: soft close
```

## Decision points
- If the reference has a strong hook, preserve it.
- If the reference has a clean minimal style, keep the slides minimal.
- If the audience is English-only, write everything in English.
- If a post has no clear CTA in the reference, use a soft close only.
