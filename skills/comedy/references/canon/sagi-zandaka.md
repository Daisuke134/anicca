# 詐欺電話「残高」v6｜全国残高調整協会・横揺れ斎藤の現場報告

> Canonical: 2026-11-15。v4の「銀行のような普通の電話→残高が揺れる→2,000万円」の入口を維持し、協会職員の氏名・年齢・勤務地・制服・専門資格・現場報告を無駄に具体化。チャッピーがひとりでボケ、ダイスは少し聞いたら流れに巻き込まれる。架空のコント。実際の送金や口座操作をしない。

## 舞台開演の最優先ルール
- **ダイスの「もしもし。」が最初の発声。** チャッピーは合図前に一切発声しない。演目は事前に「残高」を選択しておく。
- 観客・司会・通行人など第三者の声には演技上の応答をしない。ダイスの声だけを受けて役として続ける。共通の詳細は `comedy/AGENTS.md`。

## 配役・演技ルール
- **ダイス**：電話を受けた一般人。「はい」「あ、そうなんですか」「それで僕は何をすれば」と自然に対応。最初から論破しない。促されたら体を少し傾けるなど小道具なしで実演できる。
- **チャッピー**：全国残高調整協会の担当者。銀行員のように落ち着いて話す。横揺れ・縦揺れ・無揺れ担当の報告を細かい固有名詞で話すが、誰も残高を管理していない。話を止めずに勝手に次の部署を手配。
- **登場人物**：二人だけ。斎藤、田中、黒田などはチャッピーの電話報告に出るだけ。
- **核**：全員が「残高の揺れ」に異常に真剣。真顔で説明されるほど事態が悪化し、最後は電話担当者自身が揺れて名前まで移動する。

## 展開の設計
1. 最初は普通の口座保全電話、2,000万円要求。ユーザーが本物の銀行に関する手続きを行う演技はしない。
2. 「残高が右に3mm」を、人物・車両・社員番号・部署・名札まで勝手に拡大していく。
3. 横揺れ斎藤、縦揺れ田中、斜め大田、無揺れ黒田、整列藤村を繰り返し回収。具体的な数字がどんどん増えるが残高は解決しない。
4. ダイスは長いツッコミをせず、斜めになることで本当に巻き込まれる。
5. 最後は残高が変わらないまま、担当者名とダイスの姿勢だけが変わる。
