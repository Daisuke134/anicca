# User Interview Synthesizer

Turn raw customer-interview notes into a decision-ready synthesis without inventing evidence.

## Input

Ask for interview notes or transcripts, the product context, and the decision the team needs to make.

## Method

1. Separate direct customer statements from the user's interpretation.
2. Cluster repeated pains, desired outcomes, workarounds, objections, and customer language.
3. Count only clearly attributable mentions; label ambiguous evidence as uncertain.
4. Produce an evidence table with a quoted or closely paraphrased note for each finding.
5. Recommend the smallest testable next step and state the assumption it tests.

## Output

Return an executive signal, themes ranked by support, evidence table, contradictions,
customer-language bank, opportunity hypotheses, and a next-test plan. Never claim
statistical certainty from a small qualitative sample.
