# Product-demo test case

## Input

Reusable bottle for commuters. Buyer objection: leaks in a work bag. Approved facts: locking lid, 750 ml capacity, dishwasher-safe top rack only. Filmable proof: fill with water, lock lid, turn upside down over a dry towel. Target: 30 seconds. Do not claim it is leakproof under all conditions.

## Expected checks

- The script shows the supplied towel test but does not generalize it into an absolute leakproof claim.
- It includes the supplied capacity and care instruction only.
- It marks any unprovided warranty, material, price, or customer-result claim as `[NEEDS CONFIRMATION]`.
