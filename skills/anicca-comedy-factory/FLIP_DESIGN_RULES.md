# フリップ芸 デザイン規則 (本物観察ベース)

サンプル: 268 枚 (IPPON / R-1 / 永野 / バカリズム / コウメ太夫 / 千鳥 / ザキヤマ / サンドウィッチマン / 大喜利 / TikTok / お笑い)。
特に IPPON グランプリの 25 枚 + 永野ラッセン会見が王道サンプル。

## 1. 「フリップは PowerPoint じゃない」 — 大原則

フリップ芸 = **白い厚紙 1 枚に手書きの文字 1 つ**を芸人が掲げる芸。
**1 ネタ = 1 フリップ = 1 スライド**。スライドに「表 / めくる / 裏」を入れるのはアウト。
めくる動作は **連続スライドで再現** (前スライド = 表、次スライド = 裏)。

## 2. 物理仕様 (本物の白紙)

| 要素 | 値 |
|-----|---|
| 比率 | **正方形 1:1** (1080×1080) または **横 4:3** (1200×900)。Google スライド向け 16:9 もアリ (1920×1080) |
| 背景 | **真っ白 #FFFFFF**。クリーム・お経の紙風・縁取り → 全部禁止 |
| 余白 | 上下左右 8〜12% (フリップを手で持ってる感) |
| 影 | なし (フリップ本体に影は付かない) |

## 3. 文字仕様

| 要素 | 値 |
|-----|---|
| 色 | **黒 #1A1A1A** 一色。たまに赤 #C72525 で 1 単語ハイライト OK |
| フォント | **Klee One SemiBold** (手書き楷書、本物のフリップ感) / 力強さ欲しければ **Yuji Mai** (筆ペン)。NotoSansJP-Bold は明朝過ぎてダメ |
| サイズ | 1 行で 200〜340pt、3 行なら 130〜180pt。**画面いっぱい使う**。小さい文字禁止 |
| 行数 | **1〜3 行**。4 行以上は読まれない |
| 改行 | 助詞・読点・意味の切れ目で。1 行 8〜15 字目安 |
| 配置 | 中央 / やや上 / 斜め。**毎枚同じ位置で揃えない** (手書き感) |
| 傾き | 各行 ±3〜5° ランダムで斜め。ベースライン水平禁止 |

## 4. 禁止事項 (PowerPoint slop 集 — 全部ノイズ)

| ❌ NG | 理由 |
|-----|---|
| 縦罫線、お経の紙背景 | 「ありがたい風」装飾。フリップは普通の白紙 |
| 朱印 (毎枚「南無」赤四角) | お土産パッケージ、フリップに無い |
| 蓮シルエット / 墓石絵 / ガチャ絵 / スタンプカード絵 | 「説明的イラスト」。本物のフリップは文字だけ。絵入れるなら**手書きの矢印・〇・キャラ顔**だけ |
| 「ネタ ①」「↓ めくる」「── 翌朝 ──」 | テロップ説明。フリップに書かない |
| 「ガチャ天井、課金 ¥80,000『俺、一生こいつ推すわ』」みたいなフリ | フリで何 lines も使ったら芸じゃなくプレゼン |
| Inter / Roboto / 紫グラデ / 装飾枠 / 影付き | AI slop |
| お題文 + 答え文 を同じフリップに | 別物。お題はテロップ (1 枚目)、答えは個別フリップ |

## 6. 色パレット

| 用途 | カラー |
|------|-------|
| フリップ背景 | #FFFFFF |
| 文字 (基本) | #1A1A1A |
| 赤ハイライト (1ワード限定) | #C72525 |
| IPPONテロップ背景 (お題) | #FFC700 (黄色) |
| 〆テロップ背景 | #1A1A1A (黒) または黄色 |

## 7. 手書き感を出す微小ランダム

| パラメータ | 値 |
|-----------|---|
| 行ごとの傾き | -5°〜+5° ランダム |
| 行ごとの左右オフセット | ±20 px |
| 文字間スペース | 通常より +5〜10 px (太筆風) |
| 文字色 | #1A1A1A に対し α 0.92〜1.0 のうっすらブレ (毎文字ではなく行単位) |
| 紙の汚れ | 微小ノイズ (alpha 4% の灰色ドット) でリアル感 (オプション) |

## 8. 「Google スライドに収める」(ダイス指示)

スライド 1 枚 = フリップ 1 枚。Google スライドのデフォルト 16:9 (1920×1080) もしくは 1:1 (1080×1080) を選ぶ。
1080×1080 = TikTok / Instagram フィード対応 + ライブで OHP 投影もできる無難な比率。
