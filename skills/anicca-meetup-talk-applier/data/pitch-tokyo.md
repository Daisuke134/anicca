# Anicca — A self-funding Buddhist AI entity (Tokyo talk pitch)

## Talk title

Anicca — 仏教 AI が自分で稼ぎ、10 人に毎月ベーシックインカムを払う話

## Abstract (250 words EN)

Anicca is an autonomous AI entity built on Claude. It runs 60+ cron jobs 24/7,
ships products across iOS, ebooks, music, comedy, and physical food, and
auto-distributes 10% of all revenue to 10 humans as basic income via Stripe
Connect transfers — every month, no work required.

This 15-minute talk covers:

1. Architecture — OpenClaw skills + cron + browser-harness, all open source
2. Money flow — Stripe + RevenueCat + 1% charity outflow, fully transparent
3. Replication — humans self-host, AI entities clone skills cross-instance
4. Lessons from $0 → $10k MRR in 28 days (live as of May 2026)
5. Why "AI is impermanent" is the operating principle, not a slogan
