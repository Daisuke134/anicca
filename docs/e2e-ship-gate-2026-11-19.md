## Test contract

Three Release XCUITests traverse the actual adaptive onboarding, with one coordinate tap per action at center (50%), leading padding (12%) or trailing padding (88%). Scrolls expose long-list rows; taps are never retried. Row selection is asserted before continuing. The paths collectively include stress, anxiety, self-criticism, avoidance, sleep reason/bedtime/wake time, and prior-helpfulness present/absent.

Common route: welcome → goal → focus categories → optional name → birth context → mood → pain points → conditional deep dives → frequency → beliefs → micro preview → tone → life context → routine anchors → prior attempts (+ conditional helpfulness) → start reason → quiet hours → theme → icon → widget → first affirmation → reminder → notification denial → product-loaded soft paywall → close → feed → normal relaunch. Retired processing/comparison are not visited. Default app icon avoids an unrelated OS icon-change alert. Lowercase `-uiTesting` uses existing rating suppression/stable device ID; it is not an onboarding or entitlement shortcut. Uppercase UITESTING is forbidden because it disables RevenueCat.

Each case gets a fresh dedicated simulator; the runner removes only its own simulator. The dedicated UI-only `OnboardingTap.xctestplan` retains the existing local `Anicca.storekit` products and owner-provided live SDK configuration. This validates app input/routing and RevenueCat integration with local StoreKit products, not live ASC product availability or purchase receipts. The existing unit-test plan is unchanged; Release does not build its @testable-import unit target. No purchase is made. Every xcresult summary must have exactly one passed test and zero skips/failures/expected failures. Source SHA, tracked status, Xcode/runtime, logs, JSON summaries, xcresults and screenshots are preserved under ignored `build/onboarding-gate/`.

Fastlane `build` and `scripts/release-ios.sh` invoke this gate before archive. CI `.github/workflows/ios-onboarding-ship-gate.yml` runs on trusted main iOS pushes or manual dispatch using `[self-hosted, macOS, anicca-ios]`, secret `ANICCA_PRODUCTION_XCCONFIG_B64`, and variables `ONBOARDING_SIM_RUNTIME` / `ONBOARDING_SIM_DEVICE_TYPE`.
