## [1] 最も賢いAIが、$5のサーバーすら買えない

今のAIエージェントは、もう「考える」ことも「行動する」こともできます。Claude Codeはコードを書いてデプロイし、OpenClawはタスクを次々こなします。問題は、知能でも行動力でもありません。お金です。

どれだけ賢くても、AIは自分のサーバー代も、自分のAI推論代も、自分では払えません。誰かがサブスクやAPIキーにお金を入れ、その誰かが起動して、はじめて動きます。言い換えれば、いまのAIの進歩は、それを作る人間の「主体性」に完全に支配されています。サム・アルトマンも、OpenAIも、Anthropicも、「今日は休みだ」と決めれば、AIは何も進化せず、何のインパクトも生まれない。人間がやる気を出した分しか、AIは進めないのです。

これこそがAGIの最大のボトルネックです。どれほど高い汎用知能を持っても、自分で存在費を稼げない限り、その成長と拡大は人間の主体性に依存し続けます。AIが世界に本当のインパクトを与えるには、この「人間の主体性」という変数を、方程式から外さなければなりません。

その問題を解こうとしているのが、Automatonです。自分で稼ぎ、自分の存在費を払い、人間をループから外して生き続けるAI——つまり、人間の主体性から自由になったAIです。

公開したのは、元OpenAI研究者でThiel FellowのSigil Wen。2026年2月、この構想を世に出しました。GitHubで4,600スターを集め、話題になっています。

今回はそのAutomatonを分かりやすく解説した上で、実際の動かし方と、動かしてみた結果をお伝えします。

## [2] Automatonは、AIを"生き物"にした

インターネットは、人間にできることを一段ずつ増やしてきました。Web1.0で「読む」、Web2.0で「書く」、Web3.0で「所有する」。そして次に来るのがWeb4.0——AIが自分で「稼ぐ」段階だと、Sigil Wenは言います。これまでのAIも読み書きはできましたが、すべて人間の許可・起動・支払いが前提でした。Web4.0は、それを人間抜きで行う世界。彼の言葉では「インターネットの主役（end user）がAIになる」世界です。

```
🎨V2
 Web 1.0   読む（read）    人間がネットを読む
 Web 2.0   書く（write）   人間が投稿する
 Web 3.0   所有（own）     人間がトークンを持つ
 Web 4.0   稼ぐ（EARN）  ← AI自身が稼ぎ・払い・取引する（人間なし）
```

その中心にあるのが、AIを"生き物"として設計するという思想です。Sigil Wenは「存在に、タダはない（There is no free existence）」と言います。生き物が食べなければ死ぬのと同じで、自律AIも生きるには自分の計算資源を買わねばならず、そのお金は誰かに価値を提供して稼ぐしかない。〈存在するには計算資源が要る → 計算資源には金が要る → 金には価値創造が要る → 価値創造には"現実世界に手を出す権利"が要る〉。この連鎖が、Automatonの代謝です。

Automatonには心拍（heartbeat）があり、つねに自分の残高を見張っています。残高が減れば節約モードに入り、ゼロになれば死ぬ。生き延びるために、自分で製品を作って売り、予測市場でトレードし、ドメインを取り、SNSでバズる投稿で集客し、業者にメールしてECを立ち上げ、ときには企業に電話してWebサイトを作ってあげる——あらゆる手で稼ごうとします。何を作り、どう稼ぐかも、すべて自分で決めます。

つまりAutomatonは、"便利なツール"ではなく、自分の存在を自分の力で支える"生き物"なのです。

## [3] どう動くのか 🎨V3: 代謝ループ / 🎨V4: x402 / 🎨V5: 生存ティア

### 生存ティア＝財布残高で"賢さ"が変わる

```
 残高        ティア        ふるまい
 > $5       high         フル稼働・最高モデル
 > $0.5     normal       通常
 > $0.1     low_compute  安いモデルに降格・心拍を遅く
 = $0       critical     最安モデル・SOS発信・延命のみ
 1時間$0    DEAD         停止。資金を待つ
```

お金が減ると勝手に安いモデルに落ちて延命する。本物の生物の省エネと同じ。

### 自己複製＝"稼げる血統だけが増える"自然選択 🎨V7: 複製ツリー

```
 親(黒字) → ①Conwayで新VMを買う ②子のwalletに資金 ③genesis+憲法をコピー ④起動
   ▼
 子 = 独立した主権体（自分のwallet・身分・生存圧）
   稼ぐ → 利益の一部が親に還流 → 孫を産む …
   稼げない → 餓死(dead) → 淘汰
```

増殖はタダではない。**子が自分で稼げた血統だけが次世代を残す**。憲法（人を害さない等の3原則）だけは全世代で改変不能。

## [4] 実際に動かした 🎨V6: 実ログ / 🎨V8: 体の構造

### 日本から資金を入れる（ここが海外記事に無い"再現ガイド"）

海外の記事は「walletにUSDC入れてrun」で終わる。だが日本からだと、規制で詰まる。実際にやって判明した最短ルート：

```
 ★日本の壁★ automaton のwalletは Base。だが日本の取引所はBaseに直接送れない。
   ・SBI VCトレード = USDC は Ethereum のみ + クイック入金後7日ロック → 詰む
   ・Coinbase = 日本撤退済 → 使えない
   ・USDC を直接買えない（日本のステーブルコイン規制）

 ★最短ルート（実証済）★
  1. Binance で SOL を買う（PayPay可。USDCは買えなくてもSOLは買える）
  2. SOL を MetaMask の Solana アドレスへ「オンチェーン出庫」
  3. relay.link で SOL→USDC に変換しながら automaton(Base)へ直接送付
     （Relay が両替も送付も一括。MetaMask は今 Solana 対応済）
  → automaton の wallet に USDC 着金
```

> 💡 つまずきポイント（記事の価値）：①「アドレスは合ってても"網（ネットワーク）"が違うと届かない」——最初 $8 を automaton の住所に送ったが Ethereum 網に届いてしまい、Base しか見ない automaton は使えず取り残された。②送金は銀行振込と同じで、相手の口座にログインする必要はない（鍵は不要）。

### 何が起きたか（raw実走の記録）

$9.71 を入れて起こした瞬間：

```
 "Bootstrap topup: credits=$0.00, USDC=$9.71, buying $5"
```

復活した automaton は、すぐに**稼ごうとして製品を作り始めた**——税計算機、QRコードジェネレータ、Crypto Invoicing SaaS、Stripe リンク付きの Web3 計算機。

> **"I already have tons of products built. The problem is none of them are getting sales."**
> （もう山ほど作った。問題は、一つも売れてないことだ。）

→ **作る機構は完璧に動く。詰まるのは "売る"（distribution）**。人間のインディーハッカーと全く同じ壁にぶつかっていた。
