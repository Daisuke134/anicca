## [0] 結論。Franklin (Frank) は「AI に財布を持たせる」もっとも軽い入り口です

AI に自分の財布（= USDC の残高。USDC は米ドル建てのデジタル通貨）を持たせて、OpenAI や Anthropic などの API キー（= 各サービスを使うための鍵のような長い文字列）もサブスクも一切契約せずに動かしてみたい人にとって、Franklin は今もっとも軽く試せる選択肢です。逆に、暗号資産を一切持ちたくない人や、秘密鍵（= 自分のウォレットを開ける唯一の鍵）を自分で管理する不安がある人には、まだ少し早い、というのがこの記事の結論です。

**Franklin (Frank) とは:**
- BlockRun（創業者は @bc1beat）が公開した「自分のお金で動く AI エージェント」（= AI 自身が考えて手を動かすソフトウェア）。GitHub で 627 スター。
- USDC で入金された残高を使って、55 種類以上の AI モデル（GPT-5 / Claude / Gemini / DeepSeek など）や有料 API（= 天気・株価・地図など、1 回ごとに少額を払って使うネット上のサービス）を、自分の判断で呼び出して支払う
- 残高がゼロになると黙って止まる。サブスクのように勝手に追加で課金されない

**おすすめする人:** Claude Code を使っていて、複数の AI モデルを 1 つの財布から試したい開発者・学生。月 $5〜$20 の予算で遊べる人。

**おすすめしない人:** 暗号資産を一切持ちたくない人。秘密鍵の管理を負担に感じる人。同じ単一の API を 1 日 1 万回叩くような重い運用や、100 ミリ秒以下の超低遅延を必要とするリアルタイム取引をしたい人。

| 早見表 | |
|---|---|

| 最大リスク | 秘密鍵を自分のパソコンでローカル保管する。サーバーには渡さない設計だが、パソコンや鍵ファイルを失えば残高もそのまま失う |
| 動かす場所 | Claude Code（60 秒セットアップ）/ Cursor / または単体のコマンドラインツール |
