## [0] 結論。Franklin (Frank) は「AI に財布を持たせる」もっとも軽い入り口です

AI に自分の財布（USDC 残高、USDC は米ドル建てのデジタル通貨）を持たせて、OpenAI や Anthropic などの API キーもサブスクも一切契約せずに動かしてみたい人にとって、Franklin は今もっとも軽く試せる選択肢です。逆に、暗号資産を一切持ちたくない人や、秘密鍵を自分で管理する不安がある人には、まだ少し早い、というのがこの記事の結論です。

**Franklin (Frank) とは:**
- BlockRun（@bc1beat 創業）が公開した「自分のお金で動く AI エージェント」（npm: `@blockrun/franklin`、Apache 2.0 ライセンス、GitHub 627★）
- USDC で入金された残高を使って、55 種類以上の AI モデル（GPT-5 / Claude / Gemini / DeepSeek など）や有料 API を、自分の判断で呼び出して支払う
- 残高がゼロになると黙って止まる。サブスクのように勝手にチャージされない

**やったこと:**
- 実際に $5 の USDC を入れて、1 回のチャットから市場データの取得まで動かし、「どのモデルが選ばれたか」「1 回あたりいくら払ったか」「残高がどう減ったか」「日本語プロンプトでも英語と同等か」を記録

**結果（※[ ] 内は実走後に差し替え）:**
- そのまま動かすと → [選ばれたモデル: ◯◯ / 1 回あたりのコスト: $0.◯◯◯◯ / $5 で持つ回数: 約 ◯◯ 回]
- 日本語プロンプトでは → [英語と同等の tier 判定 / 過大なモデル選択 / 過小なモデル選択]
- 残高がゼロになると → [free プロファイル（NVIDIA 無料モデル）に自動 fallback / 黙って停止]

**おすすめする人:** Claude Code を使っていて、複数の AI モデルを 1 つの財布から試したい開発者・学生。月 $5〜$20 の予算で遊べる人。

**おすすめしない人:** 暗号資産を一切持ちたくない人。秘密鍵管理を負担に感じる人。同じ単一 API を 1 日 1 万回叩くような重い運用や、100ms 以下の超低遅延が必要なリアルタイム取引をしたい人。

| 早見表 | |
|---|---|
| 初期コスト | $1〜$5 の USDC。Base（Ethereum の低手数料ネットワーク）上で入金。1 回の送金手数料はおよそ $0.001 |
| 最大リスク | 秘密鍵を自分の PC でローカル保管する。サーバーには渡さない設計（手元で署名するだけ）だが、PC や鍵ファイルを失えば残高もそのまま失う |
| 動かす場所 | Claude Code（60 秒セットアップ） / Cursor / または `npm i -g @blockrun/franklin` で単体 CLI |
| 必要な前提 | Node.js 20.19 以上 |
