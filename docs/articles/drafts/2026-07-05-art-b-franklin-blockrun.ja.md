# 人間なしで、自分のお金で考えるAIを動かしてみた話

**概要**

- Franklin は、自分名義のSolanaウォレットだけを持って動く、自己資金のAIトレーダーです。
- 考えるための電気代（AIモデルの推論費用）を、自分のウォレットからその場で払っています。人間のクレジットカードは介在しません。
- 今回見ていくのは「儲かった話」ではなく、「自分のお金で考えて、無理な取引をしなかった話」です。むしろその手前で、私たちが直した2つの本物の不具合のほうが面白いので、それも正直に書きます。

## 自分の電気代を、自分で払うAI

Franklinは`BlockRunAI/Franklin-Trading`という土台の上で動く、トレード専門のAIです。特徴は一つだけです。判断のたびに必要なAIモデルの呼び出し代を、Franklin自身が自分のSolanaウォレット（`8FpqdcCHqjqkVXR58eVJa53neXbJf9emXhvHhgeUPCV9`）から、x402という仕組みで直接払っています。

x402は「使った分だけその場で払う」ための規格で、BlockRunというインフラがこれを提供しています。BlockRunは、モデルを呼ぶための土台（60種類以上のAIモデルにつながる）と、それを動かし続けるための計算資源の両方をまとめてAI向けに提供しています。人間が使うクラウドサービスのAI版だと思ってください。人間ならクレジットカードを登録するところを、Franklinは自分のウォレットの残高で直接払います。

実際にFranklinの支払い記録を覗くと、こう並んでいます。

```json
{"model":"openai/gpt-5-mini","costUsd":0.009276,"wallet":"8FpqdcCHqjqkVXR58eVJa53neXbJf9emXhvHhgeUPCV9","network":"solana:..."}
```

一回の判断につき、だいたい1円に満たない額です。これがFranklinが「考える」たびに、自分の財布から出ていっています。

## 最初の躓き：思考代だけで$0.91を溶かした

とはいえ最初からうまくいったわけではありません。正直に書きます。

Franklinの元々の設定は、強くて賢いフロンティアモデル（Opus 4.8）を使うものでした。ところが、Franklinの元手は最初$1.33しかありません。賢く考えれば考えるほど、その思考自体にお金がかかります。結果、$1.33の元手のうち$0.91を「考えるだけ」で使い切り、手元には$0.42しか残りませんでした。取引は一件もしていません。

これは、賢さと収益力は別物だという、身も蓋もない事実です。世界一賢い人が世界一の金持ちとは限らないのと同じで、AIも「頭がいい」ことと「その頭の使用料を自分で払い続けられる」ことは、まったく別の問題です。

直し方は一発では決まりませんでした。無料モデルに切り替えては空の応答しか返らず、いくつか別のモデルも試し、そのたびに結果を見ながら乗り換えるという試行錯誤の末、最終的に「無料ではないが、1回1円未満で動く安いモデル」（`openai/gpt-5-mini`）に落ち着きました。今のFranklinの通算コストは、97回の判断で合計$1.39。そのほとんどは無料モデルで$0のまま、必要なところだけ数銭を払っています。自分の財布で自分の頭を食べさせる以上、頭の値段そのものが生死を分けるということです。

## 二つ目の躓き：cronが「起きたふり」をして何もしていなかった

もう一つ、地味だけれど致命的な不具合がありました。Franklinは30分ごとに自動で起きて判断する設定になっています。ところがこの自動起動の設定に、実行に必要なコマンドの場所（PATH）を教える設定が抜けていました。結果、Franklinは30分ごとに「起きようとして」、Franklin本体のプログラムが見つからず、毎回何もせず終了する、という状態がしばらく続いていました。

直したのは一行です。自動起動の設定に、必要なコマンドの場所を教える設定を足しただけです。地味ですが、これが直っていなければ、Franklinはそもそも一度も「考える」ところまで辿り着けていませんでした。

## 三つ目の躓き：質問して終わる、という悪癖

三つ目は、もう少し奇妙な問題でした。Franklinは一回の起動につき一つの判断をして終わる設計です。ところが、判断の最後に「SOLを監視し続けましょうか？それとも他の通貨も見てみますか？」と、人間への質問で会話を締めくくってしまうことがありました。

これは一見無害に見えますが、実は深刻です。Franklinは無人で30分おきに起動する設計なので、その質問に答える人間はどこにもいません。誰も答えない質問で終わるたびに、その回の判断は事実上何もしなかったのと同じになり、次に起きたときはまた最初から考え直しになります。

直し方は、AIの判断そのものを縛るコードを書くことではありませんでした。指示文に一言足しただけです。「あなたは無人で動いている。誰もこの質問に答えない。毎回、実行するか、明確な理由付きで待つか、必ずどちらかで終われ」と。この一言を足した後の実際の判断ログがこちらです。

```
WAIT — TradingSignal for SOL is neutral/low-confidence (33%), a round-trip swap
costs ≈0.4%+ so no edge, and wallet USDC is only $1.71 (insufficient to justify
fees and keep gas).
```

質問はなく、判断とその理由だけで終わっています。AIが何を選ぶかは変えていません。AIが選び続けたときの振る舞いの形だけを、指示文の一行で直しました。

## 結局、Franklinは何をしたのか

正直に言うと、Franklinはまだ一件も実際の取引（スワップ）を実行していません。手元の資金が$1.71〜$1.80程度と小さく、Solana上でのトークン交換には往復で0.4%以上の手数料がかかります。Franklinはその都度、自分のウォレット残高とチャートの状態を自分で確認し、「今回は手数料に見合う根拠がない」と判断して、待つことを選び続けています。

これは「何もしていない」のではありません。強制的に取引を作らず、根拠のない賭けを避け続けているという、それ自体が一つの判断です。実際、アニッチャのダッシュボードには2026-07-05時点でFranklinの現在資産として実測`$3.18`が表示されており、これは自己資金・自己運用（funding: self）として実際にオンチェーンの残高から検証されている数字です（この数字はアクセスするたびに変わります）。

## この話が示していること

Franklinの土台であるBlockRunは、AIが人間のクレジットカードなしで自分の思考代を払い続けられるという、それ自体は既に動く仕組みです。今回私たちが直したのは、その土台の上で「本当に無人で、本当に安全に、本当に判断し続けられる」ようにするための3つの穴でした。思考コストが元手を食いつぶす穴、起動そのものが失敗する穴、そして判断が人間宛ての質問で宙に浮く穴です。

儲かった話ではありません。ですが、自分のお金で、自分の頭の使用料を払いながら、無理な賭けをせずに判断し続けるAIが、実際に今この瞬間も動いている。それ自体が、地味だけれど本物の証拠だと思っています。

## 最後に

私たちアニッチャは、Franklinのような自己資金AIの群れを、人間のクレジットカードなしで動かし続けることを目指しています。今回のような地味な不具合と直した記録を、これからも実データ付きで公開していきます。
