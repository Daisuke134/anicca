### P4 — Tier 1C+D+E: dead + HR#15 + 重複 × 5 削除

★ naist-pull は ★ 同名 2 entry の */15 inline python 版 のみ 削除 ★、 hourly skill 版 残す。 `openclaw cron rm <name>` が 同名 全削除 すると plan 崩壊、 事前 verify 必須。

```bash
# Step 1: verify naist-pull の 2 entry を 確認、 削除 対象 (= inline python 版 = sched=*/15) を pinpoint
python3 << 'EOF'
import json
with open('/Users/anicca/.openclaw/cron/jobs.json') as f:
    data = json.load(f)
jobs = data.get('jobs', data) if isinstance(data, dict) else data
if isinstance(jobs, dict): jobs = list(jobs.values())
naist = [j for j in jobs if (j.get('name') or '')=='naist-pull']
for j in naist:
    sched = j.get('schedule',{}).get('expr','?')
    msg = (j.get('payload',{}).get('message','') or '')[:50]
    print(f"sched={sched} | id={j.get('id')} | msg={msg!r}")
EOF

# Step 2: 同名 rm の 挙動 chk
openclaw cron get naist-pull 2>&1 | head -20  # CLI が 2 entry に どう 反応 する か確認

# Step 3: 安全 path — rm 不可 なら manual edit jobs.json で */15 inline 版 を 削除
# (= python script で 該当 entry を 配列 から 除去 → tmp 書込 → rename)
python3 << 'EOF'
import json, shutil
from pathlib import Path
p = Path('/Users/anicca/.openclaw/cron/jobs.json')
shutil.copy(p, p.parent / f'{p.name}.pre-naist-pull-fix-20260605')
with open(p) as f:
    data = json.load(f)
jobs = data.get('jobs', [])
# Filter: remove naist-pull with sched */15 (= inline python 版)
new_jobs = []
removed = 0
for j in jobs:
    if (j.get('name') or '')=='naist-pull' and j.get('schedule',{}).get('expr','')=='*/15 * * * *':
        removed += 1
        print(f"REMOVING: name=naist-pull sched=*/15 id={j.get('id')}")
        continue
    new_jobs.append(j)
data['jobs'] = new_jobs
with open(p, 'w') as f:
    json.dump(data, f, ensure_ascii=False, indent=2)
print(f"removed={removed}")
EOF

# Step 4: 残り 4 本 (trip-scanner, basic-income-monthly, article-daily-rotation-audit, +他なし) を rm
for id in anicca-trip-scanner basic-income-monthly anicca-article-daily-rotation-audit; do
  echo "=== rm $id ==="
  openclaw cron rm "$id" 2>&1 | tail -3
done

# verify total = 167 (= 171 - 4)
python3 -c "
import json
d=json.load(open('$HOME/.openclaw/cron/jobs.json'))
j=d.get('jobs', d) if isinstance(d, dict) else d
if isinstance(j, dict): j=list(j.values())
e=sum(1 for x in j if x.get('enabled', True) is not False and not x.get('disabled', False))
assert e == 167, f'expected 167, got {e}'
print('OK P4: 171→167')
"
```

**verify**: enabled = 167、 naist-pull `0 * * * *` skill 版 が 残って いる こと。

**commit**: `chore(cron-cull): P4 delete 4 dead/HR15/duplicate crons (171→167)`
