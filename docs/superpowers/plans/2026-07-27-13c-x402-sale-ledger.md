# 13c-SELL x402 sale ledger implementation plan

**Goal:** Automatically and idempotently book finalized, externally funded x402 USDC sales in the
Life Manager earnings ledger without classifying self-pay or fractional-cent rounding as revenue.

**Architecture:** Keep the deployed x402 `external-inflows-*.jsonl` files as sale-evidence SSOT.
A small Life Manager adapter validates their schema, and the production CLI independently queries
Base for chain ID, finalized head, receipt, transaction initiator, and exact USDC Transfer before
calling the existing earnings runtime. A five-minute launchd job performs the connection continuously.

**Tech stack:** Node.js CommonJS, built-in `node:test`, Base JSON-RPC, Supabase REST, launchd.
