# Q12 — Stripe Checkout -> webhook -> spawn backend (skeleton)
```js
// POST /api/checkout : create $30/mo subscription session
const s = await stripe.checkout.sessions.create({ mode:'subscription',
  line_items:[{price: PRICE_30_MO, quantity:1}], success_url, cancel_url, customer_email });
// POST /api/stripe/webhook : verify + spawn
app.post('/api/stripe/webhook', raw, (req,res)=>{
  const e = stripe.webhooks.constructEvent(req.body, req.headers['stripe-signature'], WEBHOOK_SECRET);
  if (e.type === 'checkout.session.completed') {
    const session = e.data.object;
    spawnCloudAnicca({ owner: session.customer_email });  // = Q6 DO provision, assign droplet to user
  }
  res.json({received:true});
});
```
