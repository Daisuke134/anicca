# ディスク自動回収とアプリのライフサイクル

- 作成日: 2026-08-18
- 発端: 空きが 2GB まで落ち、作業が止まりかけた。原因を測ったら「使い終わったものを閉じていない」1点に集約された

## 0. 実測（2026-08-18 深夜）

| 対象 | 実測値 | 判定 |
|---|---|---|
| 空き容量 | **2GB** | 危険水域 |
| `code_sign_clone` 総数 | **28個 / 10,211MB** | macOS がブラウザ起動時に作るコード署名用の一時クローン |
| うち使用中 | **1個**（`com.google.Chrome.code_sign_clone/code_sign_clone.kDFyhr` / 707MB） | 保持 |
| **孤児** | **27個 / 約9.5GB** | 全プロセスの `lsof` 走査で開いたハンドル 0 件 |
| 作成日時の幅 | 8/16 19:17 〜 8/18 00:59 | 起動のたびに増え、正常終了しないと残る |
| 稼働ブラウザ | PID 606 / 820、**連続 1日13時間53分** | `~/.cloakbrowser/chromium-145.0.7632.109.2/` |
| Premiere | PID 47087（10時間32分）＋ 52973（`UE` 固着 12時間29分） | メモリは 65MB / 7MB で無害。**問題は起動しっぱなし** |
| `~/.codex` / `~/.claude` | 7.4GB / 2.0GB | ★ **絶対に触らない**。セッション再開の燃料 |

**根本原因**: ジョブが終わってもアプリを閉じていない。ブラウザもPremiereも同じ。閉じないから一時領域が積み上がる。

## 1. 触ってはいけないもの（恒久）

| 対象 | 理由 |
|---|---|
| `~/.codex/sessions` `~/.codex-acct2/sessions` | Codex のセッション。消すと再開できない |
| `~/.claude` | 同上 |
| `~/.cloak/profiles/` | ログイン済みプロファイル。消したら全サービス再ログイン |
| 使用中の `code_sign_clone` | 稼働ブラウザが掴んでいる |
| `/Applications/Adobe Premiere Pro 2026`（6.7GB） | アプリ本体 |
| `source/package/` | 先方支給素材。再取得不能 |

## 2. 回収してよいもの（判定基準つき）

| 対象 | 判定基準 | 見込み |
|---|---|---|
| 孤児 `code_sign_clone` | `lsof` に開いたハンドルが**無い**もの | 約9.5GB |
| gig の旧バージョン | 納品済み最新版・その素材・先方支給物**以外** | 約2.3GB |
| `/tmp/lbj` 等の検証中間物 | 結論が spec とプロジェクトに記録済み | 約300MB |
| stale lease | lease の `pid` が**存在しない** | 0GB（だが他ジョブの妨げ） |

## 3. 自動化の設計

### 3-1. `disk-reclaim.sh`（新規・cron 化）

```
毎時実行:
  空き容量を測る
  空きが 15GB 未満なら:
    1. lsof を1回だけ走査し、開かれている code_sign_clone 名を集合として取得
    2. その集合に含まれない clone だけを削除
    3. pid が死んでいる lease を解放
    4. 前後の空き容量を state に追記
  空きが 8GB 未満なら Telegram に通知
```

**要点**: 「使っていないこと」を `lsof` の実測で判定する。日時や個数で判定しない。ブラウザは1日以上連続稼働するので、古い＝不要ではない。

### 3-2. アプリを閉じる責任をジョブ側に持たせる

| 対象 | いま | あるべき |
|---|---|---|
| Premiere | 手で起動、閉じない | `premiere-cli` に **`quit`** を追加。`export`/`collect` に **`--quit-when-done`**。ラッパー `run-job.sh` で「起動→開く→処理→保存→終了」を1本に |
| ブラウザ | lease 解放後も起動したまま | 常駐が正しい（daily-driver は forever ブラウザ）。ただし**異常終了を減らす**ため、lease を取ったジョブは必ず release する。タイムアウトで殺された場合も解放されるよう trap を入れる |

**注意**: `~/.cloak/profiles/daily-driver` の常駐ブラウザは**閉じない**。これは各サービスにログイン済みの forever ブラウザで、閉じると全部再ログインになる。閉じるのは Premiere と、ジョブ専用に起動した使い捨てブラウザだけ。

### 3-3. `premiere-cli` の追加分

```
quit                      # 保存確認 → プロセス終了 → 終了を検証
export --quit-when-done
collect --quit-when-done
doctor                    # 固着プロセス(STAT=UE)を検出して報告
```

固着プロセスは `kill -9` が効かない（カーネルI/O待ち）。`doctor` は報告するだけにして、`launch` は `open -n` で別インスタンスを立てる。これは実装済み。

## 5. 一般化（次に同じ穴に落ちないため）

**症状**: ディスクが突然枯渇する。
**誤った本能**: 大きいファイルを探して消す。
**正しい手**: 「起動したまま閉じていないアプリ」と「その一時領域」を先に疑う。`lsof` で使用中かを実測してから消す。
**一般法則**: **開いたものを閉じない設計は、必ずディスクとプロセスの両方を漏らす。** 掃除の自動化より、閉じる責任をジョブ側に持たせる方が根治になる。
**次に何を見るか**: `df` が減っていたら、まず `/private/var/folders` と長時間稼働プロセスの一覧。
