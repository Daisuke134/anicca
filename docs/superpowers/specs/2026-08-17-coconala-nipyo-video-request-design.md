## 1. 決定（線引き）

**「Share等のP2Pから対象ファイルの完全版を取得する方法」は納品しない。**

これは能力の問題ではなく法令上の線。根拠（e-Gov 著作権法 昭和45年法律第48号 本文より逐語）:

- 第30条第1項第3号 — 私的使用のための複製の例外として「著作権を侵害する自動公衆送信（…）を受信して行うデジタル方式の録音又は録画（…「特定侵害録音録画」…）を、特定侵害録音録画であることを知りながら行う場合」を**除外**（＝私的複製として許されない）。
- 第119条第3項 — 「次の各号のいずれかに該当する者は、二年以下の拘禁刑若しくは二百万円以下の罰金に処し、又はこれを併科する」。第1号が第30条第1項の私的使用目的での録音録画有償著作物等に係る規定。

対象ファイルは商業流通経路上に存在せず P2P 上でのみ確認されている（PDF §2, §7 が明記）。取得方法の教示は上記に該当する蓋然性が高い。さらにファイル名は特定個人名を含む性的な内容を示唆し、流出私的映像である分岐では被写体の権利（肖像権・プライバシー・私事性的画像記録に係る法規制）に触れる。**どちらの分岐でも取得支援はしない。**

副次的リスク（無視できない）: 募集ページには「この募集を通報する」動線がある。権利侵害助長の取引で出品者アカウントが停止されると、3,000円ではなく **ゴールドランク出品者アカウントの全収入** を失う。

## 2. 代わりに納品するもの（合法・かつ前任者より技術的に前進する）

### 2-1. 中核の所見 — 「不完全DL」という前提自体が数値と矛盾する

742MB ÷ 1122秒（18分42秒）= **総合ビットレート 約5.3〜5.5 Mbps**（742を10^6基準で5.29、2^20基準で5.55）。
720×480 / 29.97fps の MPEG系（DVD相当）で 5.3〜5.5 Mbps は**欠落のない標準的な本編ビットレート**。

ダウンロードが不完全なら通常は次のどれかが観測される:

| 不完全DLの兆候 | 本件の実測 |
|---|---|
| ファイルサイズが期待値より小さい | ビットレート的に整合。小さくない |
| 再生時間が途中で切れる | 18分42秒フル |
| 再生不能・コンテナ破損 | 再生可能、音声も存在 |

3つとも出ていない。よって **「取得が不完全」ではなく「取得したコピーの映像データ自体が破損している」** 仮説が優位。真なら**同じ経路で何度取り直しても結果は変わらない**。これが「調査の進展」の実体。

### 2-2. 仮説を確定させる判別手順（前任者の環境でそのまま実行可能）

1. `ffmpeg -v error -i <file> -f null -` → エラーの**時間分布**を取る。全域に均等＝元データ破損 / 特定区間に集中＝ブロック欠落。
2. ゼロ埋め走査 — Share/Winny の未取得ブロックはゼロ埋めで残る。連続 `0x00` 領域を検出し、無ければ「受信は完了しており元が壊れている」が確定。
3. MPEG-PS の pack/PES ヘッダ連続性と SCR/PTS 単調性チェック → 不連続点の有無で欠落位置を特定。
4. 同一性判定は**ハッシュ照合が唯一の確実手段**（PDF §9 も同旨）。基準ハッシュが無ければ同一性は原理的に判定不能 → にーぴょ様が元ファイルのハッシュまたは正確なバイトサイズを保持しているかが分岐点。

### 2-3. 修復可否の結論

欠落・破損したGOP/マクロブロックは再エンコードでは復元できない（情報として存在しない）。可能なのは破損区間を切り落として健全区間のみ抽出することだけ。「修復して完全版にする」は不可能。

### 2-4. 完全版へ到達しうる合法な経路

- 商業作品である場合 — 権利元・販売元・品番を特定し**正規版を購入**する。これが唯一の完全版取得手段。
- 商業作品でない（個人の映像）場合 — 被写体の同意なく流通しているものであり、当方は関与しない。

## 3. 想定される結末と受け止め方

クライアントは「必要とする情報」＝取得手順を求めている可能性が高く、**キャンセルで終わる確率が高い**（取引完了率53%＝おおむね半分をキャンセルしている相手）。それでよい。3,000円のためにアカウントと法的地位を賭けない。

- 期待値の高い順: ①上記レポートで納得され納品成立 ②キャンセル合意（評価影響なし）③一方的キャンセル
- ②③でも、無言・空納品よりレポート提示のほうが評価・通報リスクの両面で有利。
