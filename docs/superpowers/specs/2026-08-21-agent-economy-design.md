# Agent Economy Design

**Status:** Approved for incremental implementation

## Goal

Life Manager runs an agent-economy loop whose verified external income pays for inference and, after a separate graduation gate, its shelter. Existing Franklin, earn, wallet, x402, and ledger code remains the implementation substrate.

## Architecture

`agent-economy` is a thin policy boundary. The loop observes wallet balances, append-only receipts, opportunity outcomes, compute cost, and shelter cost; it selects one revenue adapter; a local signer enforces recipient, chain, reserve, and spend caps; every external result is reconciled from an on-chain or provider receipt. BlockRun/Franklin x402 is the primary compute rail. OpenRouter is an optional pre-funded adapter, never the autonomous funding root.

The resident process runs from an immutable `~/loops/releases/<timestamp>-<sha>` release selected by the atomic `~/loops/current` symlink. State stays outside releases. Launchd declarations are generated by `bin/plistgen.py`; no absolute worktree path is committed or installed.

## Money rules

- External realized revenue excludes self-payments, tests, returned principal, mark-to-market values, and unverified claims.
- `spendable = liquid USDC - reserve - committed liabilities`.
- Compute and shelter coverage are measured separately.
- Proposed graduation gate: 30-day external realized net is at least 1.5 times 30-day compute plus shelter cost, liquid runway is at least 30 days, and human-paid inference is zero for the same window.
- Trading is surplus-only; paid work is the first revenue lane; x402 is a stable single-product distribution lane.

## Security boundary

The model proposes actions but never receives a private key. A local signer validates chain, recipient allowlist, per-transaction cap, session cap, and reserve floor before signing. Ledger writes are append-only and idempotent by receipt identity.

## First slice

The first slice makes the resident control plane release-backed. It adds a continuous loop declaration, teaches the existing plist generator to render continuous jobs and expand home-relative environment paths, and adds a regression test proving the generated agent-economy plist points at `~/loops/current` and contains no `.worktrees` path.
