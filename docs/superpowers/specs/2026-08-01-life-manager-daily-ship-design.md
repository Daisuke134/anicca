## 0. 何を作っているか（1行）

**予定の時刻に電話が鳴り、家を出てから着くまで案内が続き、遅れたら相手に断りを入れる。** これだけ。

| 含む | 含まない |
|---|---|
| 予定 → 移動時間の自動挿入 | 体調・運動・睡眠（physical） |
| 出発の電話（T-15/10/5） | 瞑想・気分（mental） |
| 移動中の案内（乗換・出口） | 記事・SNS・収益系（別 agent の担当） |
| 遅刻時の連絡（承認つき） | UBI・法人・決済の拡張 |

**daily だけで単体で価値がある**ので、physical / mental を待たずに友達へ配る。
