## 1. 中核の問題 — 買った物と求めている物がずれている

| | 内容 |
|---|---|
| 購入された役務（＝我々の債務） | **契約書のたたき台1式**（5,000円） |
| talkroom で購入者が言っていること | 「プリントオンデマンドと寄付先の連携ができるページが作れません」「利益1000円＋推し活代1000円で決済に進めるようなサイトが欲しい」＝**ECサイト制作** |

**決定: 納品するのは契約書。ECサイト制作はこの取引では行わない。**
5,000円・契約書カテゴリ・法務経験を要件とした募集に対して購入されたものであり、サイト制作は別役務。ここを曖昧にしたまま作業を始めると、5,000円で決済連携付きECサイトを負う無限スコープになる。

**ただし購入者の8/17メッセージは「無関係な雑談」ではない。契約条件そのものが書かれている**:

| 購入者が述べた条件 | 契約書のどの条項になるか |
|---|---|
| デザインテンプレートを無料公開 | 利用許諾（非独占・無償）の範囲 |
| 「儲けた場合、一年の純利益の1%お支払い下さればビジネスパートナー」 | ロイヤリティ条項（料率1%・課税標準=年間純利益） |
| 「儲からない年はもちろん支払い義務は発生しません」 | 支払免除条項（純利益が零以下の年度） |
| 商標は**被服 第25類・国内のみ**取得 | 商標の許諾範囲と地域・区分の限定、表示義務 |
| 前面プリントのデザインのみ・ロゴマーク不使用なら無料 | 無償利用の境界（ロゴ使用は別途許諾） |
| 利益2,000円のうち1,000円を購入客が寄付先を選んで寄付 | 寄付表示・寄付先への送金責任・景表法/寄付募集の表示 |
| 他社プリントオンデマンドとの連携 | 製造委託先（POD事業者）の位置づけと品質・納期責任 |
| インボイス非対応（免税事業者） | 消費税の取扱い・インボイス不交付の明記 |

したがって **「テンプレート利用許諾契約書（ロイヤリティ1%）」が、この購入者が実際に必要としている契約書**であり、募集本文の「弊社サービスに関する契約書」とも整合する。ここに寄付連携の扱いを含める。

## 5. 実装メモ（同じ画面を触る者へ）

- ココナラのヘッダ・ナビは **shadow DOM の中**。`document.querySelectorAll('a')` では取引管理のリンクが取れない。shadowRoot を再帰的に walk すること。
- 取引一覧の正しいURLは **`/mypage/received_orders/{required|open|closed|canceled}`**。`/mypage/transactions` 等は404。
- talkroom は `https://coconala.com/talkrooms/<id>`。
- 応募文の実値は `mypage/offers/<id>` の **textarea の value**（innerText には出ない）。
- CDP直叩きは PreToolUse hook が deny する。`~/.config/ai/bin/browser-guard.sh acquire coconala:kosuke` を先に通し、コマンド文字列に `browser-guard.sh` を含めること。
- gig-daily-driver には coconala タブが複数開いている。タブIDを固定しないと毎回別タブを操作してしまう。
