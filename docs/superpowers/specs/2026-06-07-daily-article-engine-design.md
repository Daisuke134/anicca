## Phase 0-9 flow (= invoked from heartbeat task pull, NOT own cron)

```
PHASE 0  heartbeat picks task "anicca-thesis-brief"
         (= dispatcher mapping in T17d's dispatch.json)

PHASE 1  ★ news search ★
         Firecrawl signal sources (3-5 of):
           - HackerNews top 30
           - Anthropic blog RSS
           - OpenAI blog RSS
           - Sam Altman X timeline
           - X-algo trending #AGI / #AIagent
         Output: raw_signals.json (20-50 candidates)

PHASE 2  thesis filter + angle pick
         thesis_overlap formula =
           (count of {agency, alignment, AGI, Buddhist, suffering,
                      consciousness, dukkha, anatta} keywords
            in signal body) / 8
         Pick top 1 with overlap ≥ 0.6 AND not in account-history.jsonl
         last 14d. If none qualify, exit 1 (heartbeat retries next beat).

PHASE 3  firecrawl verbatim quotes
         Fetch 3-5 real-source quotes for picked angle + 1 anti-thesis
         quote (Sam Altman OR Jensen Huang OR Yuval Harari OR fresh).
         FAIL-CLOSED if <3 verbatim URL+quote pairs.
         Output: raw_quotes.json

PHASE 4  write thesis brief
         Schema: existing anicca-article-daily brief schema +
           author: "Daisuke Narita"
           thesis: "AGI must have higher agency than humans +
                    Buddhist wisdom + end suffering = equalizer.
                    Anicca is the build."
           anti_thesis: {name, verbatim_quote, url}
           personal_experience_hint: 1 short pointer to Daisuke anecdote
           structural_principle: 1 picked from pattern-article.jsonl
           target_keyword: thesis-anchored phrase
           h2_outline: 5-9 sections derived from picked structural_principle
           required_data_fields: array of {claim, source_url, verbatim_quote}
         Write to ~/.openclaw/skills/anicca-article-daily/state/
                   briefs-<date>/thesis-<slug>.json

PHASE 5  trigger anicca-article-daily skill for each channel
         (existing 6 publish scripts run unchanged):
           bash run.sh --channel zenn          --brief-slug thesis-<slug>
           bash run.sh --channel devto         --brief-slug thesis-<slug>
           bash run.sh --channel substack-ja   --brief-slug thesis-<slug>
           bash run.sh --channel substack-en   --brief-slug thesis-<slug>
           bash run.sh --channel note          --brief-slug thesis-<slug>
           # ★ aniccaai-blog channel REMOVED (Dais 2026-06-07: no traction, no auto-sync, pure disable) ★

PHASE 6  existing 7-step pipeline runs per channel
         (RESEARCH → TITLE+LEDE → DRAFT → CRITIQUE → HUMANIZE+forbidden_phrases
          → SEO gate → PUBLISH → URL HTTP 200 → record meta + history → Slack)

PHASE 7  aggregate: thesis-brief skill reads each channel's meta.json,
         confirms ≥ 3 of 5 publications show release URL with HTTP 200 (= 4 platforms × Substack JA+EN counted separately),
         then writes single roll-up entry to account-history.jsonl with
         account = daisuke-articles, signal_source, anti_thesis, urls[].
         Heartbeat marks task done.

         FAIL-CLOSED if <4 channels publish successfully.
```

|---|---|

| Phase 3 <3 verbatim quotes found | exit 1, heartbeat retries. After 3 fails, escalate per above |
| HUMANIZE forbidden_phrases match | retry HUMANIZE max 3 attempts, then `gh issue create -R Daisuke134/anicca-dais --label "ai-ready,P0,voice-leak"` with offending phrase |
| Phase 5 channel publish fails | existing 7-step retries 3× per existing skill, then write meta with error, continue. Phase 7 counts succeeded channels |
| <3 of 5 publications succeed | `gh issue create -R Daisuke134/anicca-dais --label "ai-ready,P0,article-coverage"` listing failed publications |
