# Affiliate money playbook（2026-07-14、成功者の稼ぎ方）

marketing loop の MONETIZE(affiliate)側の self-improve 正本。top affiliate が月$10k+ を作る型。loop が imitate する（cold-start bible = docs/47 と対）。

## 4ステップ loop（top affiliate の型）
```
 EPC最大の offer 選定 → レビュー/比較 content で購買直前トラフィック獲得
   → 無料価値→温め→ソフトCTA→link で温める
     → 複数 offer 同時テスト、低EPC を切り勝ち筋に張り直す
```
月$10k+ は recurring SaaS/AI(20-50%) or 高単価金融($100-1000/件)が最も再現性高い。

## 選定ルール（★最重要★）
- **EPC > commission%**。「50%×CVR0.3% < 20%×CVR3%。皆この計算せず高%に飛びつく」。EPC = 1click あたり収益が最終指標。ベンチ: digital で EPC $2=まずまず / $4=強 / $8=優秀（niche内比較のみ有効）。
- **audience 適合 > commission率**（先に見る）。オファーミスマッチだと強トラフィックでも死ぬ（product > traffic は真）。
- niche: Education 月$15k / 金融 月$9k / AI-SaaS(Jasper 25-30%, GetResponse 33-60% recurring) / hosting(実例 年$150k)。

## content→conversion
- **レビュー / "A vs B" 比較が最も転換**（bottom-funnel、"X review"検索者は購買直前）。tutorial は信頼構築(中間)で直接CVRは劣る。
- **link 配置 = 本文/文脈内埋め込み**（製品名を出してる文脈に）。※IG は bio link のみ clickable なので caption は「link in bio」CTA + bio に link。
- **★社会的証明が CVR の実証ドライバー（2.5%→8%）★**: 第三者の声・投票・スクショ・数値。「人は意見でなく証拠を欲しがる」。
- **funnel**: 無料価値(製品直結のリードマグネット)→温め→ソフトCTA→link。★コールドに直リンク禁止★。

## 商品選定
1 offer に絞る→事前セールページ→計測可能トラフィック→CTR/CVR/EPC 改善→量産。retention/LTV が商品品質のシグナル。

## scale ($0→$10k)
① 勝ち offer に集中投資 ② その周りに content 量産(SEO/ロングテール) ③ channel 追加(Email/YouTube が一貫して強い) ④ commission 単価を交渉。初期は手作業寄り・6-18ヶ月。

## self-improve（loop が模倣する核）
1. 複数 offer 同時に流す（1本賭けない）。EPC 継続計測。
2. 転換止まった offer は即差替（既存トラフィックで判定速い）。
3. 勝ち offer に weighted 配分（random→weighted）。データ不足で性急に切らない。
4. 勝ち筋が出たら新手より倍賭け。

## Do / Don't
- **Do**: EPC で判断 / 社会的証明を積む / 複数 offer 同時テスト / 勝ちに集中投資。
- **Don't**: commission%だけで選ぶ / コールド直リンク / 1 offer 全張り / 低EPC を惰性で流す。

## loop 実装（AFF-FIND + REFLECT に埋め込む）
- AFF-FIND: EPC/audience 適合で offer 選定（commission% 単独でない）。複数候補を offer.json に持つ。
- caption/bio: レビュー/比較 hook + 社会的証明 + link-in-bio CTA。
- REFLECT: sid 別 EPC を測り、低EPC offer を swap、勝ち offer に倍賭け。
