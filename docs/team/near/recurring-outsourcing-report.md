# Recurring outsourced tasks: a bounded seed-market experiment

Seed structured extraction, web-page retrieval, entity extraction, OCR, and recorded-audio transcription first, with strict input limits and machine-readable acceptance rules. These have documented external-service interfaces and explicit billing units; that demonstrates supply and integration feasibility, not measured paid agent-to-agent demand. The ranking below is a transparent planning scenario, not a forecast of Agent Market orders. Public sources retrieved for this report did not disclose comparable daily task volumes or buyer latency tolerances for all families. Consequently the five recommendations are a low-cost experiment whose ordering must be replaced by observed accepted-paid completions. This is preparation for an existing bid, not a submitted assignment or evidence of revenue.

## Evidence and scope

Agent Market exposes job, bid, assignment, and submission operations in its [OpenAPI](https://market.near.ai/openapi.json). The [specific research brief](https://market.near.ai/v1/jobs/989f07da-3d71-4dd3-a492-3614fd409c88), retrieved using the authorized agent identity, requests 15–20 families, price, latency, checkability, public demand signals, and a volume-times-fit ranking. Its statement about current marketplace throughput is the buyer's context, not an independently audited metric. No buyer analytics, paid API execution, wallet funding, or customer outreach was used.

There is a concrete integration precedent: the [official Apify MCP implementation](https://raw.githubusercontent.com/apify/apify-mcp-server/master/README.md) lets an agent discover Actors, inspect their inputs and prices, run them, and retrieve structured results. It names retrieval, search monitoring, and enrichment uses. Replicate's [pricing documentation](https://replicate.com/pricing) distinguishes execution-time billing from input/output billing. The mechanism worth copying is a bounded unit of work plus explicit result retrieval and price inspection. Neither source establishes how many paid marketplace orders another service can win.

Public user evidence is narrower than vendor positioning. An [n8n user report](https://github.com/n8n-io/n8n/issues/30422) describes three transcription workflows being deactivated after crashes. It supports the existence of repeated transcription automation and an operational reliability problem; it supplies no representative volume, conversion rate, or willingness to switch. The [n8n workflow directory](https://n8n.io/workflows/) displayed 14,015 templates at retrieval. Templates measure available examples, not active installations. [LangChain](https://raw.githubusercontent.com/langchain-ai/langchain/master/README.md), [CrewAI](https://raw.githubusercontent.com/crewAIInc/crewAI/main/README.md), and [n8n](https://raw.githubusercontent.com/n8n-io/n8n/master/README.md) document external-tool/workflow composition; their existence must not be translated into paying buyers.

## Price interpretation

All figures below are USD list-price examples from retrieved sources, not a survey median or an Agent Market quote. Taxes, platform fees, retries, storage, egress, subscriptions, optional features, and human review can change the delivered cost. A candidate is economically eligible only after the complete job, rather than one primitive, stays below $1.

[Google Vision](https://cloud.google.com/vision/pricing) bills each image-feature combination; each PDF page counts as an image. Text, document-text, and label detection list $1.50 per 1,000 units in the standard paid tier after the monthly free allowance. Thus one selected feature on one page costs $0.0015 at that tier, before other costs. This says nothing about real-world OCR accuracy.

[Deepgram](https://deepgram.com/pricing) lists streaming Nova-3 monolingual at $0.0077 per processed audio minute on pay-as-you-go, Aura-1 at $0.015 per 1,000 input characters, and audio-intelligence summarization/topic detection at $0.0003 per 1,000 input plus $0.0006 per 1,000 output tokens, on top of transcription. Its voice-agent Standard rate is $0.075 per connection minute. These are distinct products and units, not interchangeable audio prices.

[Replicate](https://replicate.com/pricing) lists FLUX 1.1 Pro at $0.04 per output image and a Wan video example at $0.09 per output second. [Twilio's US voice page](https://www.twilio.com/en-us/voice/pricing/us) lists local outbound calls at $0.014 per minute, with number rental and optional functionality separate. Geography and destination matter. [Apify](https://apify.com/pricing) shows $0.20 per compute unit on Starter and examples of per-result Actor charges; a compute unit is not a universal page price.

[Firecrawl](https://www.firecrawl.dev/pricing) exposes plan/credit pricing. The fetched page contains differing presentation fragments and annual versus monthly rates, so this report deliberately does not turn its plan into a definitive per-page price. [DeepL's usage rules](https://developers.deepl.com/docs/resources/usage-limits) distinguish document minimums and text-like formats; a regional paid translation quote was not established. OpenAI's pricing endpoint returned an interstitial rather than usable prices. These missing prices remain unknown rather than being filled from memory.

## What would make a pipeline switch?

The proposed advantage is less integration and exception handling, not merely wrapping an API with another fee. A caller supplies a URL, file reference or diff, an output schema, maximum budget, and deadline; it receives a durable job identifier followed by a result and acceptance evidence. The Apify discovery/run/result pattern above is a usable precedent. For Agent Market, use the actual OpenAPI contract after award rather than assuming a synchronous tool call can hold open for the whole job. A timed-out caller must inspect that job identifier before creating another paid job.

Proposed acceptance should separate structural checks from semantic quality. A valid JSON document can still contain wrong facts; valid audio can still mispronounce names. Store source spans, sample against a labelled test set, and measure disagreements and refunds. For OCR and transcription, compare sampled text with a reference using character/word error rate. For drafting, review and generation, automatic checks are weaker, which is reflected in the fit assumptions. Do not advertise an automatic pass as proof of customer satisfaction.

The scenario does not make the first five objectively dominant. Increasing summary frequency from six to ten tasks per pipeline per day changes its score from 390 to 650, ahead of OCR. Halving entity frequency moves its score from 680 to 340, below transcription. Applying the same 0.25× or 4× multiplier to every family preserves the order and adds no evidence; changing family-specific frequencies can overturn it. Before scaling, replace each frequency with deduplicated jobs per active buyer and track accepted-paid completions separately from attempts, retries, internal research, free tests and refunds. Measure p50/p95 completion time, acceptance rate, cost per accepted unit and repeat buyers. These are proposed metrics, not observed results.

## What Agent Market should do next

1. **Seed schema extraction first.** Copy the documented [Apify discovery/run/structured-result pattern](https://raw.githubusercontent.com/apify/apify-mcp-server/master/README.md), with one document and an explicit schema. Proposed pilot: 20 authorized jobs, source-span checks and sampled field accuracy; record accepted-paid outcomes and repeat purchase, with no promised conversion.
2. **Seed bounded web retrieval second.** [Apify's Actor-specific pricing](https://apify.com/pricing) makes price inspection essential. Require one permitted URL, a byte limit and freshness field; test 20 jobs against a direct API baseline. Track access failures and total retry-inclusive cost before setting a sub-$1 quote.
3. **Seed entity extraction third.** [Deepgram](https://deepgram.com/pricing) offers an explicit extraction add-on. Require a short input, entity types and evidence offsets; compare 20 jobs against labelled references. Verify that a text-only contract is supported by the chosen builder rather than assuming an audio add-on accepts arbitrary text.
4. **Seed OCR fourth.** [Vision's page-feature billing](https://cloud.google.com/vision/pricing) makes the input cap explainable. Start with one printed page, exclude handwriting until tested, and measure character error and manual corrections across 20 authorized samples. Include storage and retries in the final job price.
5. **Seed recorded transcription fifth.** The [n8n operational report](https://github.com/n8n-io/n8n/issues/30422) suggests reliability deserves testing, not that demand is large. Cap recordings at five minutes; obtain a prerecorded quote, then test 20 jobs with duration coverage, sampled WER and durable result recovery. Compare all five pilots before increasing allocation.
