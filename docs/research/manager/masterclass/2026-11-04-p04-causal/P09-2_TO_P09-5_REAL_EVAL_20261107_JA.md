# Manager Phase 9 P09-2〜P09-5｜実データを使ったモデル学習・評価

**実行時点：2026-11-07 JST。実行済み：REAL_DATA_LIGHTWEIGHT_MODEL_TRAIN_AND_EVAL。**
公式Figure1の公開済み効果量と日本語ミームMaMe-Reの集約評定で、新たに線形回帰・Ridge・Few-shot残差適応・校正・共有スカラーを**実際に学習し、未使用の研究／文脈に対して評価**した。**7BのBehavior Foundation Model、Centaur、Be.FM、GPT4の新規forward passや実人間への介入ではない。**

## 研究データと厳密な分割

A: Nature 2026（Ashokkumar et al., doi:10.1038/s41586-026-10742-x）のSource Data Fig1 panelA。70研究・3356方向付き比較。条件を反転した鏡像を除き1678の比較を使用。過去に記録されたGPT4による予測効果を一特徴とし、実際の集約実験効果を正解とした。元の469実験効果や119330人の参加者とは独立単位が違うため混同しない。

B: CyberAgent AI Lab MaMe-Re（https://github.com/CyberAgentAILab/mame-re）。250の日本語文脈×400のミーム候補、100000組。各ペアは5人の二値評定の平均、評価者プール2325人。score.csv・context.csv・画像の *description* 列（CC BY 4.0部分）だけを使い、漫画画像・漫画の台詞を学習入力にも公開Gitにも含めない。文脈IDで160 train、40 validation、50 test。最終20,000組は完全未使用文脈。

入力のSHA256と評価プロトコルは [固定結果JSON](evidence/P09-2_TO_P09-5_REAL_TWO_DOMAIN_EVAL_20261107.json) に保存。元データの生ファイルはGitHubに再配布していない。

## P09-2｜少数例適応とPartial Pooling

未知研究を毎回holdoutし、他の69研究から共通線形校正器を学習。ターゲット研究のSupport k=0,1,3,5組で局所残差補正。評価Queryはこれらとは別の未使用組を固定。少なくとも8組ある36研究のみ、8固定分割で評価。小さな34研究は対象外。

| モデル | Micro RMSE（割合） | Macro RMSE（study平均） |
|---|---:|---:|
| 原著の保存済みGPT4予測値（今回のforwardではない） | 0.120080 | 0.077424 |
| Zero-shot共通校正 | 0.081536 | 0.055555 |
| Partial pooling k=1 | 0.080444 | 0.054481 |
| Partial pooling k=3 | 0.080633 | 0.053669 |
| Partial pooling k=5 | **0.080257** | **0.053453** |
| k=5の完全ローカル補正 | 0.084778 | 0.055717 |

k5の研究平均の改善幅は0.002102、研究単位の探索的paired-bootstrap95%区間[0.000505,0.003788]（2000再標本化）。しかし36研究中19研究改善、17研究悪化。少数例で絶対的な本人予測を証明したものではない。鏡像は分割前に除外したが、同じ研究内の別の条件比較が共通刺激を含む可能性もある。

## P09-3｜分布変化・校正・棄権

publishedの40研究をtrain24/cali8/test8、別のunpublished30研究を外部群testとして固定。公開状況は**文化・言語の真のドメインシフトではなく代理的な群の違い**。

| 指標 | published評価8研究／107組 | unpublished評価30研究／892組 |
|---|---:|---:|
| RMSE（割合） | 0.052440 | 0.083339 |
| 90%を目標にした区間の実際の包含率 | 100.0% | 98.54% |
| 棄権後の予測保持率 | 89.72% | 88.45% |
| 棄権後のRMSE | 0.048081 | 0.074860 |

予測区間の半幅は0.242483、すなわち24.25ポイント。包含率が高くても区間が広すぎるため「精度が98.5%」としない。予測値の大きさから作った暫定棄権閾値であり、校正された個別の不確実性が分かったわけではない。研究内の依存や群間シフトに通常のConformal保証は自動的に成立しない。

## P09-4｜共有パラメータと負の転移

Nature効果の校正とミームの集約評価を、領域別の基準値＋1本の共有傾きの**極端に低容量なモデル**で比較。ミームの新領域学習では、評価ラベルを入力特徴に含めないようleave-one-context-outの過去平均を使用した。

| 学習方式 | Nature RMSE | ミーム RMSE |
|---|---:|---:|
| Natureだけ学習した傾きを転用 | 0.045406 | 0.185326 |
| ミームだけを後から学習 | **0.084516** | **0.184591** |
| 両領域を等重みで組み合わせる | 0.060228 | 0.184810 |
| 旧領域と新領域の専用ヘッド | **0.045406** | **0.184591** |

Natureの古い課題が悪化したのは実測。ただし今回の「忘却」は共有スカラー係数の容量不足を説明する反例であり、7BのBFMやEWC・PCGrad・HARPOの性能比較ではない。Natureの因果効果とミームの面白さのRMSEを同一単位の総合点にしてはいけない。

## P09-5｜別領域の強いベースラインとの比較

MaMe-Reの160文脈を学習し40文脈でRidgeの正則化を選択（α=1）、完全未使用50文脈×400候補=20000組で評価。文字トライグラム24特徴、文脈と漫画画像の*説明文*の文字重なり、長さを使用。漫画画像／台詞自体は扱わない。

| モデル | 未使用文脈のRMSE | MAE |
|---|---:|---:|
| 全体の人間評定平均 | 0.186687 | 0.151226 |
| 候補ミームの過去平均 | **0.184605** | **0.148548** |
| テキスト特徴＋Ridge | 0.184694 | 0.148692 |

新しいRidgeは単純な過去平均に**勝たなかった**。「過去平均−Ridge」のRMSE差は-0.0000895、50文脈を単位とする探索的Bootstrap区間[-0.000304,+0.000121]でゼロをまたぐ。この結果はむしろ、表現が不十分な段階で「複雑な共有モデルは優れている」と宣伝してはいけない根拠になる。

## 受入条件・限界

- 学習済みの共通Behavior Foundation Model重みはない。
- 元のNature Code OceanのRDS個票・元R解析の完全再現は、正規のダウンロード認証とMacのR環境未整備により未実行。
