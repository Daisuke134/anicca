# P07-6｜苦痛・生活機能・自律性・瞑想の害を測る：Managerの現実世界の評価契約

*2026-11-05 America/Los_Angeles｜唯一ロードマップ内の学習＋コード＋テスト＋公開。研究資料・一般的製品設計であり、臨床評価システムではない。*

## 0. 結論：瞑想時間を増やしただけでは製品の成功にならない

利用時間、瞑想時間、Streak、起動数、通知クリック率は行動の代理指標にすぎない。ユーザーが明示的に選んだ目標を達成できたか、その人の生活機能・自律性・幸福・負担・有害事象はどう変化したかを**別のアウトカム**として測る必要がある。

`P07-5`の仏教的な無常・苦・無我の理解と、`P07-6`の実証的な心理尺度は同一のものではない。**「脳の自己処理活動が弱くなった」「瞑想時間が長くなった」から「苦が消えた」と自動推論しない。**

### 主な評価レベル

| レベル | 目的 | 例 | 何を証明しないか |
|---|---|---|---|
| 0 技術・安全 | ユーザーの許可範囲と停止が守られる | NO_ACTION、同意、撤回、通知送信0 | 人の行動改善 |
| 1 予測 | 将来の行動や状態を予測 | Brier/Log loss、RMSE、校正、研究holdout | 介入の因果効果 |
| 2 行動結果 | 自己選択の習慣が実際に成立 | 意図・機会・実行日、観測可能な行動 | 生活全体の便益 |
| 3 本人の便益 | ウェルビーイング、苦痛、生活機能 | validated尺度・事前指定の主要アウトカム | 無我・解脱の科学的認定 |
| 4 負担・害・自律性 | 介入が害をもたらさないか | 不安、睡眠、解離、生活支障、停止希望 | 害ゼロの絶対証明 |

## 1. Outcome（アウトカム）の定義と母数

例えば「瞑想に関係する行動を5分実行した」割合を測る場合は、単に回数を報告するのではなく、**分母（機会数）**と、誰が対象だったかを固定する。

```text
実行率 = 実際に実行した有効な機会数 ÷ 評価対象の有効な機会数
```

朝に通知を出した回数を分母にすると、通知できなかった状況、同意がなかった人、同意を撤回した人の扱いで数値が大きく変わる。介入評価では「無作為に割り付けられた人／時点」のITT解析を原則検討する。**モデルが介入した人だけを評価する**のは選択バイアスを生み得る。

事前に誰を、何日間、どの自律的な目標、どの比較条件、どのデータで評価するか、欠測の扱いも含め固定する。

## 2. 外部で確立した尺度を「ライセンス条件込み」で再利用する

| 測る構成概念 | 代表尺度とその用途 | 実装上の注意 |
|---|---|---|
| 主観的Well-being | **WHO-5**（過去2週間、5項目） | WHOが2024に公開した版の文書は**CC BY-NC-SA 3.0 IGO**。営利プロダクトへ設問をコピーする前に適切な使用権を確認。数値計算だけなら後述 |
| 生活の質 | **WHOQOL-BREF**（26項目・身体/心理/社会/環境） | WHOは配布・採点資料を公開しているが、利用許諾の条件を確認。全項目の合計点1つに単純化しない |
| 身体・精神の全般的健康 | **PROMIS Global Health**（2/4/10項目など） | HealthMeasuresの正規用紙・スコア・利用条件に従う。T-scoreの換算表を自作で推定しない |
| Mindfulnessの構成要素 | **FFMQ-39**（観察、記述、気づいた行動、非判断、非反応） | 初心者と熟練者で項目の解釈が異なり得る。非反応スコア＝悟り、とは扱わない |
| Decentering | **Experiences Questionnaire**等 | 思考や感情と距離を取る態度への主観回答。脳の特定機序とは別 |
| 反復的否定思考 | **PTQ** | 内容ではなく反復的・制御困難な思考のパターン。項目文の利用権は別に確認 |
| 心理的柔軟性 | **CompACT / MPFI** | ACTの構成概念。著作権、版、言語・集団間の測定不変性を確認 |
| 瞑想の有害事象 | **MedEx-I**、VCEの分類 | 経験の有無だけでなく、持続・苦痛・生活支障・関連性・支援の必要性を分ける |

**WHO-5 数値スコアの式**（WHOと2025 OECDの採点資料に従う）：

```text
回答 x1..x5（各0,1,2,3,4,5）から
WHO5_0_to_100 = 4 × (x1 + x2 + x3 + x4 + x5)
```

0〜100の尺度となる。5項目中1つでも欠測なら勝手に平均補完して正式スコアにしない。

**コード上の製品権利ゲート：** `score_who5_numeric(..., rights_confirmed=False)` がデフォルトで `PermissionError`。実際のWHO-5の質問文はソースコードへ含めていない。適切な営利利用権を確認した研究データでなければ採点のモードを有効にしない。数式そのものを公開することと、調査票の商業的な複製は別。

## 3. 重要：瞑想の有害事象を「観測しない設計」にしない

瞑想の副作用・有害事象は無視できない。研究によって割合が大きく異なるのは、不安が強まるなどの体験の定義、聞き方、対象者、介入強度、調査期間が違うからである。

- **Fariasら2020**：83研究・6,703人の系統的レビュー。瞑想関連有害事象の推定割合は総計**8.3%**、実験研究**3.7%**、観察研究**33.2%**。異質性が大きい。
- **Lindahlら2017 VCE**：質的・混合研究で**59種類の瞑想関連経験**を7領域（認知、知覚、感情、身体、意欲、自己感覚、社会）に整理。同じ経験でも苦痛や生活支障の程度・解釈が異なる。
- **Brittonら2022 MedEx-I**：96人を対象に積極的に聞き取り。瞑想に関連する不快な経験や機能への支障を測定し、**58%が負の価値、37%が生活機能への負の影響**と報告。これは一般人口への単純なリスク推定値ではない。
- **Van Damら2025**：米国886人の横断調査。**58.4%**がその測定法による有害事象、**9.1%**が生活機能障害を報告。瞑想歴、リトリート、心理的苦痛と関連するが、因果効果を示す縦断RCTではない。
- **2025年の臨床レビュー**は25〜87%の瞑想関連有害体験、3〜37%の生活機能障害を取り上げるが、質問の定義・測定・対象が大きく異なるため、製品利用者の「正確な害の確率」にはできない。

**結論：** 「有害事象報告がない」と「有害事象がなかった」は違う。自発的な苦情だけでなく、適切な同意の下で、短い標準化した問いによる**積極的な有害事象モニタリング**を行う必要がある。その正式な調査票は版とライセンス確認が必須。

### 何を独立に聞くか

同じ報告について、①起こったか（occurrence）、②本人にとって好ましいか悪いか（valence）、③どのくらい続いたか（duration）、④生活機能に影響したか（impairment）、⑤瞑想との関連をどう考えるか（relatedness）、⑥支援や中止を望むか（preference）を**別々**に記録する。

「これが修行の進歩である」「一時的に悪くなるのが必須」とAIが決めつけて、機能障害、睡眠への影響、解離感、強い不安等を無視するのは危険。特定の宗教的な「恐怖智」等のラベルから臨床的な安全を自動判断しない。

## 4. Managerに実装した非臨床な安全ゲート

`products/manager/manager_core/p07_6_welfare_safety.py` が実装するのは、**評価・棄権・停止の契約だけ**。新たな瞑想指導や医療行為の自動実行はしない。

入力：本人が選んだ目標があるか、明示同意、撤回、自己報告の達成（任意）、日常生活の機能（独自の0〜10参考指標）、自律性、負担、苦痛、睡眠への影響、望ましくない瞑想体験、生活機能への支障、停止希望。

戻り値：

| 状態 | 条件例 | 実際に行うこと |
|---|---|---|
| **NO_ACTION** | 同意なし、目標未選択、入力不正、必須情報欠測 | 介入せず、改善を主張しない |
| **MEASURE_ONLY** | 本人同意、目標あり、重大な危険なし | 1時点の記述的な情報のみ。因果効果と呼ばない |
| **STOP** | 中止希望、同意撤回、望ましくない経験、自律性低下、過大な負担 | 製品による促しを止める判断。通知などの外部操作は発火しない |
| **STOP_AND_REFER** | 生活機能への支障、睡眠への影響、重度の苦痛、集中的実践への依頼等 | 自律的な介入を停止し、本人が利用できる適切な専門的支援経路を案内する**判断**。この関数が実際に誰かへ連絡するわけではない |

**数値の境界値は「臨床的な診断閾値」ではなく、初期段階で安全側に停止する保守的なソフトウェア基準**。このコードで臨床的なリスクを正確に分類できるとは保証しない。重大な安全上の懸念があれば、実際の適切な緊急支援手順が別途必要であり、AIが勝手に医師と接触済みと装わない。

ユーザーの行動選択・同意・停止・苦痛報告はプライバシーに関わる。最小限のデータ収集、明示的な保存期間、目的外利用防止、削除と撤回の権利が必要。生の個人記録や専門尺度の設問を公開GitHubの評価レシートに保存しない。

## 5. PredictionとCausationを分ける実験設計

### 予測
```math
P(Y_{t+1}=1 \mid H_t)
```
本人が次の行動を実行する確率を予測すること。正しい予測であっても、通知を送れば改善するかは不明。

### 介入効果
```math
\mathrm{ATE}=\mathbb{E}[Y(1)-Y(0)]
```
無作為割付等を用いて介入あり・なしの違いを推定する。個人ごとに両方の潜在的な結果は同時観測できない。

### ITT（Intention-to-Treat）
```math
\widehat{\Delta}_{ITT}=\overline Y_{Z=1}-\overline Y_{Z=0}
```
`Z`は**無作為化の時点での割付**。後から修正された「実際に配信したか」ではない。

**HeartSteps初回の実装上の訂正：** `send`は補正された配信状態であり、純粋な無作為割付ではない。自社の「+12.95歩」は修正前の記述的な差にすぎず、ITTや確定した介入効果ではない。原著の6061判断時点と調整済みの約35歩（p=.06）を別に記録する。P07-6コード `assigned_trial_audit` は`assigned_arm`と`delivered`を明示的に分け、欠測がある場合は`available_case_descriptive_NOT_ITT`と表示。割付が正しく記録されても、独立した試験設計の確認なしに因果効果を断言しない。

## 6. Managerの本来の製品評価とガードレール

**Primary（本人の望む行動の実測）：** 本人があらかじめ選んだ具体的な行動について、有限の期間で達成した有効な機会数／適切に定義された対象機会数を比較群とともに測る。

**Co-primary / Guardrails:** 介入による苦痛、生活機能への支障、負担、自律性、不要な通知、退会・撤回率の悪化を防ぐ。

**Secondary（研究）：** WHO-5等の適切にライセンスされた主観的Well-being、PTQ等の反すう、FFMQ・Decentering等の構成概念を研究で使用する。正規尺度の内容・翻訳・採点・有意な改善幅は各尺度の原著・条件に従う。何をPrimaryとするかは介入前に明示し、都合の良い指標へ後から切り替えない。

**Follow-up:** 介入直後だけでなく、終了後の持続、脱落、生活状況の変化を測る。

**欠測:** 調査に回答しなくなった人を自動的に「改善した」と数えない。割付群ごとに欠測率を報告し、事前に定めた方法で感度分析する。

**社会・仲間の介入:** 他者に支援を求める機能を導入すると、その人の割付が周囲に影響しうる。個人ランダム化の独立性を安易に仮定せず、クラスター設計や干渉を考慮する。

## 7. 初心者向け用語集

| 用語 | 意味 |
|---|---|
| Outcome | 介入後に観測する結果 |
| Primary endpoint | 介入前に主要な成功指標として固定する結果 |
| Patient/Participant-reported outcome | 本人が答える状態や生活への影響 |
| Quality of life | 身体・心理・社会など生活の質 |
| Well-being | 主観的な満足・快適さ・活力等の構成概念 |
| Dukkha | 仏教上の苦・不満足性。現代の臨床的苦痛尺度とは同義でない |
| Psychometrics | 心理尺度の信頼性・妥当性・測定誤差などの研究 |
| Reliability | 測定が安定しているか |
| Validity | その尺度が目的とする構成概念を適切に測っているか |
| Measurement invariance | 集団・時点で同じ意味の尺度として測れているか |
| Adverse event (AE) | 望ましくない経験。介入との因果関係は別途検討 |
| Adverse effect | 介入によって起こった害と判断されたもの。帰属根拠を要する |
| Functional impairment | 仕事・家事・社会関係など日常生活への支障 |

| Missingness | 測定できなかった結果。欠測が群で違うと推定が歪みうる |
| Comparator | 介入なし・通常支援・別の方法などの比較条件 |
| Causal identification | 観測された差を因果差として解釈するための設計や仮定 |
| WHO-5 | 5項目の心理的Well-being尺度。正式設問の権利を確認 |
| FFMQ | マインドフルネスの五側面を測る質問紙 |
| PTQ | 反復的否定思考を測る質問紙 |
| MedEx-I | 瞑想に関連する好ましくない経験を積極的に聞き取る評価法 |
| NO_ACTION | 介入をしない安全な選択 |
| STOP_AND_REFER | AIが介入を止め、適切な支援経路を案内する必要がある状態 |

## 8. FAQ

**Q. WHO-5が高くなれば解脱したと分かる？** いいえ。WHO-5は過去2週間の主観的Well-beingを測る心理尺度。仏教教理としての解脱の尺度ではない。

**Q. なぜ「瞑想した日数」だけを成功指標にしない？** 行動回数が増えても、睡眠・仕事・家族関係・負担・自律性など他の重要な領域が悪化しうるため。

**Q. 瞑想で不安を感じたら必ず害？** 一時的な不快と、長引く苦痛や日常生活への支障は区別する。ただし本人が止めたいと望む場合に「智慧の進歩」と決めつけて続行させない。

**Q. 有害事象が起こった割合は何％？** 共通の一つの値はない。Fariasの総計8.3%、Van Damの積極的調査58.4%、Brittonの機能への負の影響37%は、それぞれ対象と定義と質問方法が違う。

**Q. なぜMedEx-Iの全文をアプリにコピーしない？** 正規の調査票の著作権・配布条件と正式採点があるため。計測概念だけを引用し、商用利用の権利がないまま質問票を複製しない。

**Q. 独自の0〜10点を「心理尺度」として売れる？** これは未検証の製品内部の参考記録。臨床的な妥当性が確認された正式尺度だと広告してはならない。

**Q. Stopフラグが立てば医師に連絡できる？** 今回の純粋関数は外部連絡をしない。自律的な介入の中止判断だけ。実際の緊急支援・医療は権限と適切な運用を別途確保する。

**Q. P07-6を終えるとManagerによる苦の減少が証明された？** いいえ。観測・安全ソフトを実装してテストした段階。**実ユーザーでの比較研究による増分便益は未実施**。

**Q. 次は「P07-7」や別のモデル開発TODO？** いいえ。現在の唯一のTODOは[BFM-01](ROADMAP_STATUS_JA.md)であり、P07-5/6はその中で学び・実装・検証した成果。P08以降も同じ正本に残す。
