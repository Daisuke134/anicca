## 4. 判定ロジック

```python
if not plan_hashes_match:
    raise ValueError("plan mismatch")

if missing_independent_real_receipts:
    actual_profit = None
    impact_status = "NOT_MEASURED"

if no_real_comparator or no_appropriate_consent:
    causal_claim = False
    live_release = False
```

- 実研究に出現した効果が正しくても、現実の比較データ・公式支払・害・費用が揃わなければ認定しない。
- モデルが自分の成果を説明する文章は、独立した結果の証拠ではない。
- `provider_receipt`は外部サービスの受理であって、製品利用や現金入金の確認ではない。
- 全データの時刻・モデル・許可・対象の同一性を保ち、後から得た情報を予測時点へ漏らさない。
- 本人の健康・心理尺度を使う場合、同意/研究倫理/必要な安全監視、用途制限を先に確認する。
