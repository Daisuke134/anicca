# P12-2｜長期の人間への便益・害・社会影響を科学的に評価する

**Phase 12 Masterclass / 2026-11-08。講義・架空例・出典整理。実利用者の改善を観測したものではない。** 学習進捗はROADMAP_STATUS_JA.md、製品実装の実行優先順は統合SSOTのMG-01〜MG-18を参照。二重の運用ロードマップを作らない。

## 1. 問題：行動変化 ≠ 人生の改善

モデルが「人が通知を開く確率」を当てても、行動が改善するかは不明。行動が増えても、生活の質・自主性・安全性が改善するかも不明。短期のproximal outcomeと、本人が本当に重視するdistal outcomeを区別する。

JITAIはdecision points / tailoring variables / intervention options / decision rules / proximal outcomes / distal outcomesで設計される。Micro-randomized trial (MRT)は介入時点で繰返し無作為化し、近接効果とその時間変化を評価する。長期価値には別の追跡と比較が必要。
- https://pmc.ncbi.nlm.nih.gov/articles/PMC9755932/

## 2. Longitudinal Causal Estimand

固定割付Aの時点tの潜在アウトカムは Y_t(a)。時点ごとのIntention-to-Treat Effect（割付の効果）は
Delta_t = E[Y_t(A=1)-Y_t(A=0)]。

逐次方策piを比較するときは、割付一回でなく方策全体の潜在結果Y_t^piを考え、
Delta_t(pi1,pi0)=E[Y_t^pi1-Y_t^pi0]。
逐次無作為化・一致性・positivity・時間依存交絡の扱いが必要。過去のdelivery statusと真のrandomization assignmentを混同しない。

補助的なMixed Model：
Y_it = beta0 + beta1 A_i + beta2 t + beta3 A_i*t + b_i + epsilon_it。
beta3はモデルで仮定した時間変化の差。適切な推定対象・時間構造・欠測仮定なしに単純なbeta3を因果効果と断定しない。

## 3. Longitudinal研究で行うべき実務

1. 研究対象・eligibility・割付単位・primary distal outcomeと追跡時点（例：baseline/2/4/8/12週）を**前向きに**固定する。
2. proximal：短期目標達成・反応。distal：本人が望む生活機能・長期負担・well-being。害は独立した主要ガードレール。
3. ITT：割付後の通知到達や継続利用だけで選別しない。as-treatedとの解釈を分離。
4. 反復測定と同一人物依存：person cluster、mixed-effects/GEE、必要に応じてIPW/G-methods。研究設計に合う推定器を選ぶ。
5. Missingness：追跡不能・無回答・撤回・技術エラーは同義ではない。全員を0で埋めない。MAR/MNAR仮定に対する感度分析・最悪最良境界を示す。
6. 配信割付、配信成功、実際の行動、本人が報告した価値、害を別のeventとして記録。
7. 研究途中の変更、同意撤回、停止、予想外の有害事象を調査/対応し、報告で省略しない。

CONSORT 2025は30項目の試験報告に、有害事象、欠測分析、参加者の流れ、介入の実際の提供、open scienceの記載を要求する。
- https://www.bmj.com/content/389/bmj-2024-081123
- https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-08

## 4. 完全架空の脱落例（100人×2群）

介入群：100名割付、80名測定、測定者の成功60名→75%。
対照群：100名割付、90名測定、測定者の成功54名→60%。
**観測者だけの差+15 percentage points**は、割付した100名全体のITT差ではない。

未知の人を全員0/全員1とする最悪・最良境界（成功率差）：
lower = 60/100 - (54+10)/100 = -0.04
upper = (60+20)/100 - 54/100 = 0.26。
この[-4,+26]ppは無仮定の幅の一例であり、95%信頼区間でも実際の研究結果でもない。欠測機構が効果推定を逆転させ得ることを示す。

## 5. 本人の価値・機能・害は別次元

Outcome vectorとして、GoalAttainment、Well-being、Functioning、Autonomy、Burden、Harm を分ける。重み付けで安易に総合Score化しない。行動回数/クリック率/収益だけで個人の苦の減少を代理しない。

WHO-5は過去2週間のwell-beingに関する5項目・6段階の自己報告尺度。公式2024版の文書はCC BY-NC-SA 3.0 IGO等の条件があるため、商用製品への無断転載をしない。
- https://www.who.int/publications/m/item/who-ucn-msd-mhe-2024.01
- https://cdn.who.int/media/docs/default-source/mental-health/who-5_english-original4da539d6ed4b49389e3afe47cda2326a.pdf

尺度はウェルビーイングの一部を測るものであり、悟りや全苦の終結を証明しない。他の尺度との同時取得は負担や測定反応性を生むため、目的・権利・妥当性・負担を整理する。

### Meditation関連の害：科学的に過剰一般化しない
2025年に公表された瞑想経験者886名の横断調査では、困難な経験や機能障害の報告があった。2026年に報告された短時間デジタル瞑想のRCT二次解析は別の設計・定義・期間で苦痛やnegative affectを評価した。両者の発生率を安易に比較・単一の危険率にしない。
- https://journals.sagepub.com/doi/10.1177/21677026241298269
- https://pubmed.ncbi.nlm.nih.gov/42735902/
本人の自己決定・中止・相談手段を保つ。精神健康の診断や臨床介入を無断でAIに任せない。

## 6. 社会への波及
利用者iの結果は自分の介入a_iだけでなく、他者の割付a_-iの影響を受ける可能性がある。潜在結果Y_i(a_i,a_-i)を考え、直接効果とSpilloverを分離。Group-randomized / cluster-robust analysis、ネットワークでのExposure mapping、介入が関係ネットワーク自体を変える問題を考慮する。架空シミュレーションを社会的な因果証拠と呼ばない。

## 7. Benefit–Harm–Costの評価設計
短期利益、長期便益、金銭利益、害、ユーザー自律性を同じ単位に無理に換算しない。可視化・意思決定では多目的最適化と個別ガードレールを使う：
max E[GoalOutcome(pi)] subject to P(serious_harm|pi) <= acceptable_bound, cost <= budget, valid_permission=true.
ただし稀な害の推定には大きなサンプル・外部監視が必要で、統計的に未検出という事実は「害が0」の証明ではない。

## 8. 教育・検証・製品の3つの受入基準
- **教育**：近接/遠位、ITT/observed-only、脱落バウンド、harm/welfare、CONSORTを説明できる。
- **方法論の合成デモ**：結果の欠測を0へ勝手に変換せず、範囲計算とデータ契約を検査できる。
- **実際の製品有効性**：権限・倫理・設計・長期追跡・比較群・被害対応・再現に通った場合のみ認定する。
