# P12-1｜独立再現レポートの書式（第三者用）

このファイルは外部の研究者が結果を提出するための**空テンプレート**。この報告を著者自身が埋めても「第三者による再現完了」にはならない。

## 1. 外部Reviewerの同定
- 氏名・研究機関または匿名Reviewer ID：
- 元著者チームとの独立性：
- 利害関係：
- 実施日時・環境：

## 2. 再現対象
- 論文・Claim ID・評価対象と母集団：
- source_commit_sha：
- code SHA256：
- データSHA256と正規取得方法：
- モデル/adapterのhash・ライセンス：
- OS・CPU/GPU・Python・依存パッケージ：
- 実行コマンド、設定、seed、費用：

## 3. 結果
- 原著の主要指標・分母・CI：
- 別実行の主要指標・分母・CI：
- 元の計算方法との差：
- 異なる人・研究・時期での追試範囲：
- パーサー失敗、欠測、負の結果：
- すべての差異・変更箇所：

## 4. 判定
REPRODUCED_WITH_AUTHOR_ARTIFACTS / REPLICATED_WITH_INDEPENDENT_METHODS_AND_DATA / PARTIAL_OR_UNCLEAR / NOT_REPRODUCED / NOT_ATTEMPTED

同じ著者が同じデータを使って別計算しても上位二つを選んではいけない。

## 5. 署名・訂正・不一致
- Reviewer結果の独立証拠URL：
- 結果アーティファクトのSHA：
- 再現できなかった箇所：
- 著者側の応答・訂正版へのリンク：
- 公開できない個人情報・権利制限の扱い：

独立再現が成立した後でも、別の集団・長期効果・実介入の有効性まで証明したことにはならない。
