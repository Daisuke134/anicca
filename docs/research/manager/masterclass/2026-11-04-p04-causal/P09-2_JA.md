# P09-2｜Zero-Shot・Few-Shot Adaptation・階層モデルと部分プーリング

更新：2026-11-06（Mac上の実行日2026-11-07 JST）。**研究講義＋実データの軽量モデル学習・評価**。個人レベルのBFM学習ではなく、Nature 2026公開Figure1の研究レベル実験効果を利用する。元RDS・元R解析の完全再現ではない。

## 1. 何を予測したいのか
Managerは初めて会う個人や未経験の研究について予測したい。しかし全員のデータを大量に集めることはできない。共通表現からゼロショット（事前の本人のラベルなし）で予測し、許諾済みの少数ラベルで更新するのがFew-shot。既知の人の履歴を入力する設定と、純粋に初対面の人を扱う設定を分ける。

行動反応の例：同じネタでも、言葉遊びが好きな人・身体的表現が好きな人で評定が異なる。一般LLMの性格プロンプトと本人の実測回答は別の入力条件。全員に固定した反応予測だけでは個人差を十分に表せない可能性がある。

## 2. 部分プーリング：集団と個人を組み合わせる
各人 i の未知の好みパラメータを theta_i と置く。階層ベイズモデルの典型例は
theta_i ~ Normal(mu, tau^2)
y_ij ~ Normal(theta_i, sigma^2)
と表す。個人の観測平均を ybar_i、観測数を n_i とすれば、単純な共役モデルでは事後平均は
E[theta_i|D_i] = [n_i*tau^2/(n_i*tau^2+sigma^2)]*ybar_i + [sigma^2/(n_i*tau^2+sigma^2)]*mu。
観測0件では集団muに寄り、データが増えれば本人の平均へ移る。極端な少数例のノイズを完全な個人真実として採用しない。
- Complete pooling：個人差を無視する。少数例には安定するが異質性を無視。
- No pooling：人ごと完全独立。少数例では不安定。
- Partial pooling：集団推定と本人のデータを精度に応じて組合せる。

実務の軽量形：残差の本人平均 delta_hat = sum(y_k - yhat_global_k)/(k+lambda) とし、yhat_person = yhat_global + delta_hat。今回の例はlambda=5を事前固定、個人ではなく「研究ごとの反応効果」への適応として評価。

## 3. 先人の再利用
- MAML（Finn, Abbeel & Levine, ICML 2017）：多数のタスクを学習し、新タスクに少量のデータと少数の勾配更新で適応できる初期パラメータを得る。https://proceedings.mlr.press/v70/finn17a.html
- Centaur（Binzら, Nature 2025）：Psych-101、160実験、6万人超の選択、1,000万試行超、参加者holdoutに加え未知の課題構造・領域を評価。学習済み重みや権利を確認し、権利がない場合は文献上の基準として扱う。https://www.nature.com/articles/s41586-025-09215-4
- 人間の好みの階層化：Bradley–Terry–Luceや階層回帰が、少ない個別選好から予測分布を作る強い最初の比較対象。日本語の実データ研究Who Laughs with Whom?（EMNLP2026）も参照。https://aclanthology.org/2026.emnlp-main.66/

## 4. 今回実際に学習・評価したモデル
入力はNature 2026公式Figure1の公開済み集約効果。70研究に合計3,356方向付き比較があるため逆向きペアを除去し1,678比較に正規化。元の人間個票・LLM生回答を今回学習したわけではない。

研究を丸ごとholdoutし、他の69研究で線形の共通補正を学習。その研究の25%を毎回未使用Queryとして先に固定し、残りからk=0,1,3,5対をSupportとして使う。少なくとも8対ある36研究を対象とし、残り34研究は少数例適応の評価対象から除外（ただし他研究の共通補正器の訓練には含まれうる）。各研究8回の決定的なsupport/queryの分割を実施。総行数を独立した36×8研究と呼ばない。

| モデル | Query RMSE（割合） | Study macro RMSE（割合） |
|---|---:|---:|
| 元GPT4保存予測（今回の新推論ではない） | 0.12008 | 0.07742 |
| Zero-shot研究間線形補正 | 0.08154 | 0.05555 |
| 部分プーリングk=1 | 0.08044 | 0.05448 |
| 部分プーリングk=3 | 0.08063 | 0.05367 |
| 部分プーリングk=5 | 0.08026 | 0.05345 |
| 完全ローカル補正k=5 | 0.08478 | 0.05572 |

36研究のmacro RMSEで、k=5部分プーリングはzero-shotより平均0.00210改善。ただし個別には19研究で改善・17研究で悪化。探索的な研究単位bootstrap（2,000回）による改善の95%区間は[0.000505, 0.003788]。これは事前登録された有意差検定ではなく、研究ごとの派生比較の依存や元GPTモデルの事前学習汚染まで解消するものでもない。

**結論：** 複雑な個人適応の前に、集団からの補正と少数の残差補正を比べる。完全ローカルより部分プーリングがこのデータで有利だった。しかし、本人の選好履歴の個人化が実証されたわけではない。

## 5. 設計上の落とし穴
- 同じ研究の逆向き比較を一つずつsupport/testへ分割しない（今回は反転対を落とした）。
- 同じ研究の別コントラストは共通条件を共有するため、完全に独立した新刺激とは限らない。
- ターゲット本人のラベルを使うと、それはzero-shotではなくfew-shot。
- support数kだけではなく、supportの選ばれ方・観測前後の時間・許諾範囲も記録する。
- 大きなモデルでも、個別データが少ないと過適合やプライバシー侵害の危険がある。

## 6. Managerへのモデル実装契約
History（許可済）→shared behavioral encoder z→population head→optional small personalized adapter→calibrated output。adapterは少数のデータに応じた階層縮小・正則化・元の共通表現の維持を検証。初期比較：集団平均/直前値/GLM・Ridge/階層ベイズ/少数例適応/許可済みBFM。個人情報を公開Gitへ入れず、本人の同意を越えたデータ収集や内面診断をしない。
