## 1. Vipassanā（ヴィパッサナー）の意味

`vipassanā` は伝統的には「洞察」「明晰に見ること」という観想実践を指す。現代のマインドフルネス介入にはこの伝統の影響があるが、瞑想プログラム全般や商品としてのマインドフルネスとヴィパッサナーを同一視しない。特定の10日間リトリートも、ヴィパッサナーの唯一の定義ではない。

`samatha`（止・静穏や集中の涵養）と `vipassanā`（観・経験の性質に関する洞察）は対立する二者択一と限らない。初期経典・注釈文献・現代のマハーシ方式、ゴエンカ方式、森林派等では教示・体系・強調点が異なる。

### 四聖諦（Cattāri ariyasaccāni）：SN 56.11
1. 苦諦：条件に依存する生の諸相は不満足さや苦を伴う。五取蘊を中心に説明する。
2. 集諦：苦の成立に渇愛や取が関わる。
3. 滅諦：渇愛と取の滅により苦は止むと説く。
4. 道諦：八正道が苦の終滅へ至る道として示される。

単純に「何も欲しがるな」とは読まない。伝統的には正精進・覚醒を志す意図もある。「望む目標を持つ」ことと「苦を作る渇愛」を、語義も文脈も問わず同一視しない。**科学的主張**として「この教えによって苦が減った」と立証するには、明示したアウトカムと正当な比較が必要。

## 2. 三相：Anicca / Dukkha / Anattā

| 原語 | 日本語 | 教理的意味 | 科学的に可能な研究と、できない推論 |
|---|---|---|---|
| **Anicca** | 無常 | 条件づけられた現象は変化し、固定したものとして保てない | 感覚・感情・思考・行動の時間変化を測れる。しかし変化したという事実だけで「智慧を獲得した」と判定できない |
| **Dukkha** | 苦 | 不快な痛みに加え、固定できないものを安定した満足の源として掴む不安定さ | 苦痛・反すう・生活支障を測れる。しかしDukkha全体は単一の現代心理尺度と同義ではない |
| **Anattā** | 無我 | 五蘊を「恒常で自在に支配できる私」「私のもの」と認めないという洞察の対象 | 所有感・主体感・自己関連処理を測定できるが、デフォルトモード・ネットワーク活動から無我を認定できない |

### 五蘊（Pañcakkhandhā）

色Rūpa（身体・物質）、受Vedanā（感受の快・不快・中性）、想Saññā（識別・知覚）、行Saṅkhārā（意志的な形成作用）、識Viññāṇa（対象への意識）。

**注意点：** `vedanā` は「複雑な感情」全体ではなく、まず経験の快・不快・中性のトーンである。嫌悪に伴う怒りや反すうとは区別する。五蘊は現代の脳の五領域に一対一に対応しない。SN 22.59は、五蘊について「これは私のもの、これが私、これが私の自己」との同一視を問い直す。

## 3. 四念処（Satipaṭṭhāna）— MN 10 / DN 22

| 伝統的な観察枠組み | 日本語と例 | Managerの安全な「観察のみ」の表現 |
|---|---|---|
| Kāyānupassanā | 身：呼吸、姿勢、歩行、身体の動作等 | `domain=body`、本人が選んだ自己報告 |
| Vedanānupassanā | 受：快・不快・中性の感受 | `domain=feeling_tone`、`pleasant/unpleasant/neutral/unsure` |
| Cittānupassanā | 心：貪り・怒り・集中などの心の状態 | `domain=mind_state`、臨床診断ではない主観記録 |
| Dhammānupassanā | 法：五蓋・五蘊・六処・七覚支・四聖諦などに照らす観察 | `domain=dhamma_categories`、悟りの分類ラベルではない |

四念処は全員に必ず順番どおり起きる四段階という意味ではない。宗教的な実践としては倫理・精進・正念・集中も背景にあり、単に感覚を受動的に眺めれば何でもよいという理解は粗い。MN 10の英訳と注釈には伝承による違いもある。

## 4. 縁起（Paṭiccasamuppāda）：条件による生起

SN 12.2の12支の伝統的な順序は**無明→行→識→名色→六処→触→受→愛→取→有→生→老死**である。その中心の部分を行動科学に接続するなら、

```
触（接触） → 受（快・不快・中性） → 愛（渇望・嫌悪） → 取（執着）
    |              |                         |
観測刺激       本人の感受報告            反応とその後の行動
```

「触から受へ」という経典上の条件構造を、心理学の反射やTransformerのattentionと**同一の物理機序だとすることはできない**。

### 操作化の実例

`V_t`=時刻tに報告した不快な感受、`U_t`=本人が報告した反応したい衝動、`A_{t+1}`=次の実際の行動、と定義する。

```text
P(A[t+1] = habitual_avoidance | reported_vedana[t], context[t])
```

この予測は、現象の関連を学ぶもの。介入を行った場合にどう変わるかは、許可された適切なランダム化などで別に検証する。仏教の12支そのものの因果構造をモデルが証明したと呼ばない。

## 5. 観智（ñāṇa）と伝統的な16知

上座部のヴィスッディマッガやマハーシ・サヤドーの修行論では、洞察の知識を細分化して説明する。代表的な16知は：

| 4 | Udayabbaya | 生起と消滅への洞察 |

これは**特定の伝統における宗教的・解釈学的な段階体系**。誰にでもこの順序で起こる心理状態の普遍的なデータセットではなく、単に「恐れ」が強いと第6段階だと判定するのは不適切。瞑想関連の苦痛を「進捗」だと決めつけて医療や支援の必要性を無視することは危険である。初期経典と後世の段階論を文献史上でも区別する。

### 2024年7T fMRIの研究と限界

*Deconstructing the self and reshaping perceptions*（NeuroImage, 2024, PMID 39653180）は、**熟練瞑想者1人に4時間・26ランの7T fMRI**を測定したケーススタディ。複数の主観的なStages of Insightと全脳活動の相関が報告された。自己関連処理と関わるmPFC・側頭極の活動低下、知覚・注意関連領域の変化等が含まれるが、**1人の精密観察から万人共通の神経マーカーや悟りの因果機序を認定することはできない**。神経信号から「今第何観智」と自動判定する製品機能は未検証。

参考：Mahasi Sayadaw *The Progress of Insight*、Yangら2024 *NeuroImage*。著者の理論やケーススタディは重視するが、その範囲を超える宣伝をしない。

## 6. 心理学・脳科学と統合する際の「仮説ラベル」

- **predictive processing / active inference** は脳の予測と予測誤差を研究する数理理論。無常の「洞察」を「prior precisionを下げた」ことと同一視する実証はない。本人の反応性の変化などを測る介入仮説は組める。
- **meta-awareness / decentering** は経験や思考への気づきと関わる研究概念。伝統的な無我・解脱そのものの測定ではない。
- **DMN / PCC / mPFC** は機能的ネットワーク・脳領域。特定の活動低下が一義的に「自己がなくなった」を意味するわけではない。
- **nonreactivity** は、特定の刺激への行動反応性の自己報告・行動測定で検証できる。しかし「反応しない人の方が悟っている」という価値判断を自動化しない。

## 7. 実際にManagerへ実装した部分

`products/manager/manager_core/p07_5_experience_observation.py` に、**四念処の分類を参考にした非臨床・読み取り専用の観察データ契約**を実装。

- 本人の明示同意・撤回を最初に確認。
- `domain`: body / feeling_tone / mind_state / dhamma_categories。
- `reported_valence`: pleasant / unpleasant / neutral / unsure。
- 任意の「反応したい衝動」0〜10、「行動したか」は本人の自己報告であり、診断ではない。
- **新たな瞑想指示・通知・精神疾患診断・悟り認定・神経マーカー判定・外部実行は一切行わない**。
- 強い瞑想セッションや臨床治療を求められた場合は、別の安全な経路が必要として中止・棄権する。研究のn=1を製品内の認定器として流用しない。
- 観察分類は単なるプロダクト内の仮説的な特徴設計で、現時点で**validated scaleではない**。

P07-6の安全モジュールを先に適用すべき状況（睡眠支障、機能障害、強い苦痛、停止希望など）では、そちらの停止判断が常に優先。

## 9. FAQ

**Q. 無我は「私が存在しない」こと？** それだけでは仏教原典の議論を正しく表せない。SN 22.59では、五蘊を恒常・自在の自己として捉えることが吟味される。自己感覚が変化したという主観報告を一律に悟りと扱わない。

**Q. 苦は痛みやストレススコアと同義？** いいえ。生理的痛み・主観的苦痛・Dukkhaという教理的な苦は重なる場合があっても同義でない。Managerは後者を単一0〜100点で計測できたと宣伝しない。

**Q. 無常への洞察があれば苦しみは必ず減る？** 伝統的教理上の説明と、実際の人を対象とした因果試験の証明を区別する。人ごとに介入の便益・害を慎重に測る。

**Q. 16観智は誰にでも同じ順番？** 特定の後世上座部修行体系として重要だが、万人に共通する神経科学的16段階ではない。

**Q. 7T論文で無我が証明された？** 1人・26ランの詳細な神経現象学的関連は重要だが、汎用的な診断基準ではない。

**Q. なぜManagerは精神的な段階を判定しない？** 観察記録と宗教的認定・臨床診断を分けるため。本人の幸福や害、選択の自由を守る。

**Q. 次の独立した「学習TODO」は？** 存在しない。P07-6も同じ学習・実装・安全性評価サイクルの一部。唯一の正本は[ROADMAP_STATUS_JA.md](ROADMAP_STATUS_JA.md)。
