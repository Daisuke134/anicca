# P04-4｜誰に何が効くか：CATE・介入効果の異質性・媒介分析

**更新日：2026-11-04／講義と完全架空RCT・数値検証完了。** 実ユーザーへの通知・広告・心理的介入は行っていない。学習状況の唯一の正本は `ROADMAP_STATUS_JA.md`。

## 0｜前回からの接続

P04-1で `P(Y|A)` と `P(Y|do(A))` を分け、P04-2でRCTとATE、P04-3で観察データの識別（g-formula・IPW・AIPW・DiD）を学んだ。今回は「平均的に効くか」から「**どのような状態の人に効くか**」、さらに「**どのような経路で効くか**」へ進む。

重要：個人の真の反実仮想は観測できない。CATEは`X=x`という特徴を共有する人々の平均効果であり、個人の確実な結果ではない。

## 1｜ATEとCATE

二値処置`A∈{0,1}`、処置前共変量`X`、潜在結果`Y(1),Y(0)`について、

\[
ATE=E[Y(1)-Y(0)],\quad CATE(x)=E[Y(1)-Y(0)\mid X=x].
\]

ATT（処置群平均）とCATEを混同しない。

\[
ATT=E[Y(1)-Y(0)\mid A=1].
\]

対象人口の違い・特性Xの意味・測定誤差・結果スケールによって解釈が変わる。効果修飾（effect modification）の探索では、事前指定したサブグループと探索的に発見したサブグループを区別する。

## 2｜シミュレーターの設定と完全な生データ

`experiments/p04_4_heterogeneous_effects.py`、乱数seed=`20261144`。架空の24,000人をランダム化し、通知`A=1`と通知しない`A=0`を比較。特徴は`motivation_pre∈{0,1}`（事前意欲）と`fatigue_pre∈{0,1}`（事前疲労）。

対照群の理論的完了確率と介入効果を次で設定：

\[
p_0(x)=0.22+0.18\cdot motivation-0.05\cdot fatigue
\]

\[
\tau(x)=0.16-0.20\cdot motivation-0.06\cdot fatigue
\]

\[
p_1(x)=p_0(x)+\tau(x).
\]

全員の潜在結果を人工世界内部で生成し、RCTの割当`A`に対応する結果のみ観測可能として取り出す（コードの`oracle_y0`／`oracle_y1`は**人工世界でのみ存在する答え**）。現実の個人の反実仮想を観測したわけではない。

全24,000行の架空CSVは `evidence/P04-4_SYNTHETIC_DATA.csv`。列の説明：
- `synthetic_person_id`：架空人物ID。
- `motivation_pre`, `fatigue_pre`：処置前の2特徴。
- `random_assignment`：無作為割当。
- `observed_outcome`：観測可能な二値のタスク完了結果。
- `train_split`：方策学習用の行かを示す。評価では未学習の行だけを使用する。
- `oracle_probability_no_treatment`, `oracle_probability_treatment`, `oracle_cate`：発生器内部の教育用正解。モデルの実行時特徴として使わない。

## 3｜実行したRCTの結果

| 状態：motivation, fatigue | 理論CATE | 推定CATE |
| --- | ---: | ---: |
| 低, 低 | +16.0ポイント | +17.67ポイント |
| 低, 高 | +10.0ポイント | +9.82ポイント |
| 高, 低 | −4.0ポイント | −4.54ポイント |
| 高, 高 | −10.0ポイント | −11.36ポイント |

対象標本での**理論ATE=+2.924ポイント**、RCTでの**推定ATE=+2.684ポイント**。平均ATEがプラスでも、一部の状態では処置が悪影響を与える。

標準誤差は2群の二値データの標本分散で計算し、`estimate±1.96SE`の近似95%区間を各群に出力する。予め4群を固定したが、多重検定を行う場合は複数比較に応じた手続きが必要。

## 4｜CATEから介入方策へ

単純化した方策：

\[
\pi^*(x)=\arg\max_{a\in\{0,1\}}\{E[Y(a)\mid X=x]-c(a,x)\}.
\]

今回の演習は便益がタスク完了のみ、コスト0として最適化する教育用の例である。本番では本人の利益、撤回、連絡負担、有害事象、長期効果などを別途評価し、最適化の対象に明示する必要がある。

人工データの約60%で事前定義した4群の群間差を学び、残り9,619人（学習未使用）を対象として、ランダム割当確率`e=0.5`を利用したIPWオフポリシー評価を実行。

- 学習した方策：低意欲群には通知、高意欲群には通知しない。
- ホールドアウトでの、通知なし方策に対する推定増分：**+6.279ポイント**。
- 近似95%区間：**+4.842〜+7.717ポイント**。
- 人工世界の生成式から分かる理論増分：学習方策**+6.418ポイント**、全員への通知**+2.865ポイント**。

同じデータでルールを選び、そのまま都合よく採点することを防ぐため、学習・評価を分離した。なお今回は低次元・無作為化・一定の条件に設定された人工世界であり、実人間の個別化効果は何も証明していない。

## 5｜CATEのための機械学習

- **T-learner**：`m_0(X),m_1(X)`を別モデルで予測、差を取る。
- **S-learner**：`m(A,X)`を一つのモデルで学習し、`m(1,X)-m(0,X)`を使う。
- **X-learner**：観測済み群と反対側の結果を補完して効果を学習する。
- **R-learner**：処置と結果の予測残差に基づき、交絡と効果修飾を分けて学ぶ。
- **Causal forest**：効果が異なる層を樹木集団で探索、honestyによる推定の独立性などを用いる。

一般にはデータ分割、処置確率のoverlap、CATEの不確実性、効果修飾探索の多重性、モデル間比較、外部研究への移植を評価する。介入の推定効果を正としただけで行動を自動実行しない。

参考：Wager & Athey (2018), DOI:10.1080/01621459.2017.1319839／GRF documentation https://grf-labs.github.io/grf/reference/causal_forest.html

## 6｜媒介分析：どうして介入が効くのか

考える経路：通知`A→気づきM→タスク完了Y`（間接経路）と`A→Y`（直接経路）。

独立誤差を持つ、非常に単純化した線形構造モデル（`n=20,000`、別の架空連続結果）：

\[
M=0.15+0.30A+0.08X+\epsilon_M
\]

\[
Y=1.0+0.12A+0.40M+0.07X+\epsilon_Y.
\]

この人工構造下では、
- 理論直接効果 = `0.12`
- 理論間接効果 = `0.30×0.40=0.12`
- 理論総効果 = `0.24`

今回の最小二乗の推定結果は**直接0.1212／間接0.1206／総効果0.2418**。このパス積の解釈にはモデルの線形性、相互作用・未測定交絡の不存在など、強い条件が必要。

自然直接効果／自然間接効果の一般的な識別は、`Y(a,m)`と`M(a)`のネストした潜在結果を含み、条件によりcross-world independence、媒介と結果の交絡調整、処置後交絡の不存在などが要求される。**処置AのRCTだけで媒介M→Yの因果効果が証明されるわけではない。**

## 7｜Managerへの接続と安全ゲート

現段階での研究設計案：
1. 誰について、どの結果を、どの期間に変えたいか定義する。
2. 介入前に測れた特徴だけでCATEの層・モデルを作る。
3. 不確実性・overlap不足・不公平な負担を別々に報告する。
4. 「介入しない」「本人に聞く」「追加実験する」を正式な選択肢にする。
5. 本人の同意と実施権限を事前に確認し、シャドー評価から始める。
6. 実際の便益・害・費用を独立に測る。

苦しみの軽減を目指す場合、完了率やエンゲージメントだけを利益とみなさず、心理尺度、本人の価値観、自律性、負の影響を検証する。
