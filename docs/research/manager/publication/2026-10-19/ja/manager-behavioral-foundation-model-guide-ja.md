# Introducing Manager：Behavioral Foundation Modelをゼロから理解する — 競合比較・用語集・FAQ

*2026年11月6日｜Anicca｜モデル・製品・科学的評価を一つにつなぐガイド*

**Managerは行動基盤モデル（Behavioral Foundation Model）を目指すAIモデルであり、役に立つプロダクトである。** 研究発表だけの事業ではない。本人が自分で選んだ行動や目標を支援し、変化が本当に起こったかを確かめるためのモデルを作る。

ただし現在、**汎用Managerモデルの独自重みはまだ公開していない**。公開モデル・実人間の観測データ・既存の介入研究・評価コードを組み合わせて、実装と学習を同時に進めている。

## そもそもFoundation Modelとは何か

**モデル**とは、入力された情報から確率や結果を予測する学習済みの関数である。例えば、ある人が明日歩くかを、これまでの歩数、時間帯、予定などから予測する。

**基盤モデル**とは、多くの場面に共通する表現を学び、異なる課題に転用できるモデルである。GPTが文章のさまざまな仕事に利用できるように、人間の選択・習慣・報酬・注意・社会的相互作用を共通の表現で扱えるなら、それは行動基盤モデルの候補になる。

しかし「明日歩かない確率は80%」と予測できても、歩くよう促した場合の増分効果は分からない。**予測と因果介入は別の課題である。**

## 競合から何を学ぶか：SimileとArtificial Societies

[Simile](https://www.simile.com/) は、人間の行動をシミュレーションし、企業が実際の意思決定の前に仮説を検証する製品を提供している。公式サイトは実人間のデータでの継続的な検証と予測の確信度を前面に出し、7,000件超の評価を公表している。これは**同社の公表値**であり、独立に再計算した共通スコアではない。

[Artificial Societies](https://societies.ai/) は、実際の人に基づくペルソナ、社会ネットワーク、意見の相互影響を組み合わせる。公式説明では1,000件のアンケートに対する分布精度86%（同社定義で、人間の再回答一致率上限91%と比較）を報告している。これも**企業独自の評価**だ。

両社が優れているのは、サイトを見た瞬間に「何をシミュレーションし、何の意思決定に役立つか」が伝わる点だ。Managerも曖昧なAIの擬人化ではなく、**できること・現在の精度・エビデンス・使い始める方法**を示す。

## ゼロから発明しない既存部品

| 既存の成果 | 何を提供するか |
|---|---|
| [Centaur](https://www.nature.com/articles/s41586-025-09215-4) | Psych-101の実人間の選択を使って訓練した70B認知モデル |
| [Be.FM 1.5-4B](https://huggingface.co/befm/BeFM1.5-4B) | Qwen3-4Bを基礎にした小型の人間行動予測モデル |
| [BehaviorBench](https://github.com/umich-foreseer/behaviorbench_eval) | 既存の行動科学の予測評価コード。コードMIT、データは別ライセンス |
| [HBCP](https://humanbehaviourchange.org/prediction-tool) | 禁煙RCTの介入内容・集団・環境・結果を機械可読化した予測基盤 |
| [HeartSteps](https://github.com/klasnja/HeartStepsV1) | 実際に歩行を促す通知を無作為化し、歩数を測定した研究 |
| [RCT Bench](https://bingkaiwang.github.io/RCT_Bench-main/) | 125件の既存RCTの参加者・介入・アウトカムを共通形式にしたデータ |
| [UpliftBench](https://github.com/binshuangli/uplift-bench) | 介入効果の個人差を推定する方法と評価指標の比較 |

Aniccaで実行したのは、BehaviorBench公式のソフトウェアテスト41件成功・3件スキップ、HBCPの405研究・971介入群を使ったstudy-disjoint予測、HeartStepsと3件のRCT Benchのアウトカム再計算である。HBCPのRandom ForestのMAEは9.45パーセントポイントだった。ただし、これらは**Manager自身が人を助けた介入RCTではない**。

### HeartStepsの実験設計で見つかった重要な落とし穴

初回の公開データ再計算では、使用可能な6,590レコードのうち、`send`（配信された通知の補正済み状態）を使って比較し、観測差+12.95歩を報告した。しかし、元のデータ構築コードを再確認すると、`send`は**割付時点の無作為な指示そのものではなく、後から修正した配信状態**である。元論文では別の選定基準で6,061の意思決定時点を分析し、調整済みの介入による歩数増分は平均35歩（p=.06）と報告している。

したがって**初回の+12.95歩を介入の因果効果として解釈することはできない**。数字を消して成功に書き換えるのではなく、何が違い、何が未再現なのかを公開する。これもベンチマークを作る会社に不可欠な品質管理である。

元研究：[HeartSteps原著](https://pmc.ncbi.nlm.nih.gov/articles/PMC6401341/)、[データ構築コード](https://github.com/LisaGotzian/HeartSteps/blob/master/build_heartsteps_data.R)、[初回実行ログ](https://github.com/Daisuke134/life-manager/actions/runs/42099736589)。

## まず覚える専門用語（Word list）

| 用語 | 初心者向けの意味と例 |
|---|---|
| Model（モデル） | データから規則を学び、入力から出力を予測する計算の仕組み。 |
| Foundation Model（基盤モデル） | 多くの課題に再利用できる共通知識を学んだモデル。大きければ自動的に基盤モデルになるわけではない。 |
| Open Source（オープンソース） | コードをライセンスに従って利用・変更できる状態。データや学習済み重みとは別。 |
| Open Weight（オープンウェイト） | モデルの学習済みパラメータを取得できる状態。訓練データや再現コードの公開は必ずしも伴わない。 |
| Inference（推論） | 学習済みの重みを更新せず、新しい入力に対する予測を得ること。 |
| Fine-tuning / LoRA（追加学習） | 既存モデルを特定用途に適応。LoRAは主に小さな追加行列を学習する。 |
| Simulation（シミュレーション） | 仮想条件で起こりそうなことを計算する。現実の実測とは区別する。 |
| ABM（エージェントベースモデル） | 個々の仮想人物や組織を動かし、相互作用から全体の結果を調べる。 |
| Benchmark（ベンチマーク） | 同じデータ、ルール、指標でモデルの性能を比較する仕組み。 |
| Baseline（基準モデル） | 前回値を予測するなど、比較のための簡単な方式。 |
| Holdout（未知データ） | 学習には使用せず、後から実力を測るために残したデータ。人・研究単位で分けることが重要。 |
| RCT（ランダム化比較試験） | 介入の有無などを偶然によって割り振り、できるだけ公平に結果を比較する実験。 |
| MRT（マイクロランダム化試験） | 同じ人について、1日に何回も小さな介入の割付をランダム化する実験。 |
| JITAI（適時適応介入） | 本人の状態と状況を考え、必要なときだけ支援する方式。 |
| ITT（割付に基づく解析） | 通知を読まなかった人も、元々割り当てた群に含めて評価する。 |
| Intervention（介入） | 歩行を促す通知、環境の変更、If-Then計画など行動に影響するための行為。 |
| Outcome（アウトカム） | その後に実際に測る結果。歩数、習慣達成日数、ストレス、生活の質など。 |
| Causal Effect（因果効果） | 介入した場合としなかった場合の結果の差。相関と違い、正当な実験や仮定が必要。 |
| ATE（平均介入効果） | 対象集団全体における介入の平均的な差。 |
| CATE（条件付き平均介入効果） | 状態や特徴が似た人に限った介入の平均的な差。 |
| Uplift（増分効果） | 介入によってどのくらい結果が増えると予測されるか。元から行動する確率とは別。 |
| Confounding（交絡） | 他の原因によって介入の有無と結果の関連を誤って因果と考える危険。 |
| Bootstrap（ブートストラップ） | 観測単位を何度も抽出し直して推定値の不確実性を調べる。人の繰返し記録なら人単位で行う。 |
| 95% Confidence Interval（95%信頼区間） | その方法を何度も繰り返すと95%の割合で真の値を含むように構成した区間。 |
| QALY（質調整生存年） | 生存期間を健康状態の質で重み付けした指標。医療で使用される。 |
| COM-B | 行動をCapability（能力）・Opportunity（機会）・Motivation（動機）から整理する枠組み。 |
| BCT / BCTTv1 | 行動変容技法。BCTTv1には93種類の技法が整理されている。 |
| BCIO | 行動変容介入・対象・文脈・アウトカム等を結びつける機械可読オントロジー。 |
| HBCP | Human Behaviour-Change Project。実際の介入研究の記録から予測モデルなどを作る研究基盤。 |
| HeartSteps | 本物の参加者に歩行支援を行った実験と公開データ。基盤モデルの名前ではない。 |
| RCT Bench | 既存の複数RCTを共通形式で扱えるようにしたデータ集。 |
| RNT / PTQ | 反復的否定思考、その強さを測定するPerseverative Thinking Questionnaire。 |
| Calibration（確率較正） | 70%と予測した事象が、似た予測を集めたとき実際に約70%起きるかを見る。 |
| Policy（方策） | いつ・どの支援をするか選ぶ規則。NO_ACTION（何もしない）も選ぶ。 |
| Off-policy evaluation（オフ方策評価） | 過去に集めた行動・割付確率・結果から別の方策を評価する方法。条件を満たさなければ推定できない。 |

## よくある質問（FAQ）

**Q1. Managerはもう汎用行動基盤モデルなのか？**

目標と製品カテゴリはBehavioral Foundation Modelだが、新しい汎用の学習済み重みはまだ公開していない。既存モデルや実データの評価器を統合している段階である。

**Q2. GPTのようなチャットモデルと何が違うのか？**

自然な文章だけでなく、実際の人の選択、行動変化、どの介入がどんな条件で有効かを予測・検証することを目指す。ただし因果効果には追加の科学的検証が必要。

**Q3. HeartStepsの+12.95歩は本当の介入効果なのか？**

いいえ。初回再計算は後から補正した配信状態による記述的な差。元研究の無作為割付を正確に再現した因果推定としては使えない。

**Q4. BehaviorBenchで勝てば人間の苦しみが減ると証明できる？**

できない。予測精度と本人にとっての便益・害は別の指標。独立した人間対象の介入評価が必要。

**Q5. なぜ既存モデルを利用するのか？**

Centaur、Be.FM、HBCP、HeartSteps、RCT Bench、BehaviorBench、UpliftBenchには既に検証できるコードやデータが存在するから。再発明より、その性能と不足を実測する方が速い。

**Q6. 反すうや心理的苦痛を減らせるのか？**

CBTなどの研究はあるが、Manager自身の有効性は未実証である。専門治療を提供できると主張せず、本人の安全と自律性を守る。

**Q7. 次に何をクラウドで実行する？**

適切な利用権限を取得し、Be.FM1.5-4Bをクラウドで実際に推論する。Qwen3-4Bと同じ入力で比較し、権利が確認された実人間holdoutへ進む。

**Q8. 学習TODOと開発TODOは別なのか？**

**別ではない。** 既存の実装を理解し、動かし、比較し、Managerへ接続し、公開するまでを1つの仕事とする。唯一の作業順・完了条件は[Managerの単一ロードマップ](https://github.com/Daisuke134/life-manager/blob/main/docs/research/manager/masterclass/2026-11-04-p04-causal/ROADMAP_STATUS_JA.md)に集約する。

## 1つの製品開発サイクル

**Learn → Run → Measure → Integrate → Ship → Publish。**

同じ事実を繰り返し調べ直さないため、記事は出典・実行コード・実際の結果・不確実性にリンクする。モデルが失敗した場合も数値を残す。現実で役立つことがすべての基準であり、ブログや学術論文はその経緯と結果を公開する手段である。
