# Manager BFM-02｜公開4Bモデルの日本語ミーム人間評価：厳密な実行契約

2026-11-07 JST。対象：Qwen3-4B-Instruct-2507-Q4_K_M公開GGUF、llama.cpp固定b12137。原著著者のMaMe-Re 2026 Findings EMNLPの人間評価データを使用。**Centaur70B／Be.FM4Bの推論ではない。** この本文は実行環境・評価契約であり、モデル成績は対応するGitHub Actionsの正規artifactだけを正解とする。

## 実験目的
初めての日本語文脈で、二つの漫画コマの「説明文」のどちらが面白い返答になるかについて公開4Bモデルの実回答を比較する。**漫画画像や元の漫画台詞はモデル入力へ渡さない**。画像・キャプションを用いる原著のマルチモーダル完全条件とは異なり、文脈＋一般的な説明文によるtext-onlyの非常に限定されたpilot。

## Splitとプロトコルの固定
P09-5で固定した160train、40validation、50testのcontext IDを再利用。全250のIDが一度ずつで重複なし。テスト50のうち24文脈をseed=20261107で選ぶ。候補選択は**train160文脈の歴史的なアイテム別平均評定だけ**を使い、12組は過去平均の上位/下位候補、12組は過去平均が近い候補。A/Bの提示向きは固定乱数で決定。人間のテスト正解のスコアはモデルの候補選択にもプロンプト生成にも使わず、結果の集計時だけ参照。

## 独立な人間評価との比較の定義
Human_A=当該文脈とA候補について別途集計された5票の面白さ率、Human_B=同様に5票の面白さ率。人間のA/B直接対戦投票ではない。Human_A==Human_Bはtieとして正答率の分母から外し、tie数を必ず報告。
Qwenの回答はA/Bの一文字指定。厳密に読めない場合はinvalidとして**不正解に含める**。条件付き正答率とinvalid込みの厳格正答率を分離する。過去のアイテム別平均が高い方を選ぶ非常に強いsimple baselineを同じ24件で採点。改善しない場合、正直に記録する。モデルの生成結果ではなく、別の人間による集約評定を正解として測る。

## 実行結果の受入
- 過去の実データBFM-01はrun 42365475377、6秒の架空配分ゲームのみで正解率なし。
- BFM-02の初回PR run 42366972924はUbuntu PythonにNumPyなしでソフトウェアテスト停止。修正でHeartStepsの小さな回帰をstdlib依存にし、16/16ユニットテスト成功。
- 次のrun 42367178766は実際の4bitモデルをダウンロードし、最初の6モデル生成まで実行したが、厳密なA/B抽出に失敗し、さらに非UTF8出力でUnicodeDecodeErrorとなってジョブ失敗。**これを成績成功とは数えない**。
- その後のrunは文字コードによるクラッシュを防ぎ、実際に生成された回答だけを限定診断する修正版。正本となる成績はstatus=successかつArtifactのJSONをreadbackしてから本文へ確定記入する。

## 今回は示せないこと
個別の2,325人の誰が笑うか、音声・動画・漫才の演技への反応、創作したネタが高評価か、元論文のランキングを再現したか、CentaurやBe.FMに勝つか、Managerの介入によって現実の人間の幸福が増えるか。これらを一度の24文脈のテキストpilotから推論しない。
