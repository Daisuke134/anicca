# Manager G0〜G3｜Zero-UI基盤の実装・実測レポート

2026-11-07。**G0 / G1 v1 / G2研究ヘッド v0 / G3オフラインShadow v0**を、既存Life Manager正本に接続する独立作業として実施。これは**実ユーザーに対する無言の監視・誘導・本番介入ではない**。

## Zero-UIと権限の分離

- ユーザーは専用Manager UIや毎回の承認を使わず、既存の正当なサービス経路から支援を受けられる設計を目指す。
- ただし、未知の人への秘密のプロファイリング、無承諾のセンサ取得、本人の自律性を奪う心理的な操作は行わない。既存ホストが合法に取得した許可を尊重し、必要な開示・撤回・停止手段はホスト側で保障する。Apple App Store Review Guidelines 5.1がデータ収集と用途の開示・同意・撤回を要求する点と整合。
- 現G3は**公開集約データしか使わず**、実世界の通知・実行・データ外部送信を0に固定。User profileの作成や実人間の心理状態推定は0。

## G2｜実際に学習し保存したHBCP行動結果モデル

モデル：products/manager/evals/hbcp_train_v0.py。HBCP公開の405研究／971介入群、数値93特徴、元データSHA eec4ba6ffc51961fda1308f690a97a60111d93858fa67ca19ffd4392fd49679b 。HBCPの元論文で基データCC0 1.0が明記されている（https://pmc.ncbi.nlm.nih.gov/articles/PMC12603517/）。個別人間モデルや臨床判断の権限ではない。

Study IDのSHAで**283研究の学習／40研究の校正／82研究の最終テスト**を凍結（それぞれ689/85/197介入群）。中央値補完・標準化・係数学習に校正/テスト行を一切使用せず、固定Ridge alpha30をfitした。モデル重み93個、変換パラメータ、モデルSHA、分割SHA、Calib幅、テスト指標をJSONとして保存。モデルファイルの再ロード後、実行した公開介入群特徴量から予測値を算出できる。

## G3｜読み取り専用Zero-UI Shadow

コード：products/manager/manager_core/zero_ui_shadow_v0.py。既存のAuthorityVerifierとHMAC fixture grantを再利用。研究用の公開集約シグナル（30以上の集約観測、固定元データSHA、タイムスタンプ）、**G2の実モデル保存重み**による推論値だけを入力する。enabled=Falseを既定にし、欠けた/失効した権限や個人履歴・小さすぎる標本ではNO_ACTIONを返す。外部接続/書込/送信APIはない。

実公開研究データを使ったP0テスト：
- status=SHADOW_ONLY、world_action=NO_ACTION、provider_writes=0、notifications_sent=0、personal_profile_created=false。
- 971件の研究介入群の集約セットから一件の**公開介入群の特徴ベクトル**へ予測値23.1213pp、訓練平均16.1761pp。これはその介入の効果/本人の幸福度ではなく、研究用のアウトカム予測。
- 署名は**テスト用fixtureのHMAC**であり、実サービスでの正式な同意や権限ではない。本番へ接続していない。

## 次の実装カーソル（唯一の既存ロードマップの下で実行）

1. G1を実評価器として固定し、モデル更新ごとに回帰テストと版情報の差を比較。校正/棄権/未知個人・時代・文化の検証は追加が必要。
2. G2は**単純平均より良いモデル**を実際に訓練するまで研究用。合法な複数領域で共有Encoder/Adapterを学習し、少数例・負の転移・推論コストまで比較する。Be.FMは商用規約解釈が不明、Centaur70Bは重み約141GBで同条件推論は未実行。
3. G3は既存のホストサービスで正当な権限・開示・撤回が成立したP0 Shadow接続、実データの権利/目的限定/タイムカット、観測可能な本番レシートが必要。人に知られない個別監視・誘導は要件ではない。
4. G4〜G6：非臨床の限定的に望まれた価値を提供し、本人の利益・負担・害を独立計測するMRT/RCT、費用/収益/利益レシート、段階的な公開。人間を強制・欺く自動介入や証拠なき万能性は許容しない。
