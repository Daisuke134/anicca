## 1. 今回やったこと（earn 一本、diagnosis→proof→recipe）

- **loop が稼がない真因を実ログで特定**: 脳(Sonnet)は正常・valid tool_call を出してる。真因は registry.json で zero-capital earner が `status:"dormant"` = available slot に載らない。live な earn は capital-trading だけ → broke agent は narrate に落ちる。（T13/MCP は earn の blocker では**ない**）
- **x402-sell serve を修理**: 真因は Node 版でなく node_modules 欠落だった。clean `npm i` で解決。`GET /research` が valid な HTTP 402（USDC $0.003 を wallet に要求）を返す。
- **x402 mechanism を Base mainnet で E2E 証明**: automaton が claude-p の service を $0.003 USDC で購入。tx `0xd7a82586…` status=0x1（on-chain own-eyes 検証）。★但し buyer=automaton/seller=claude-p = self-pay = INV-7 で revenue 非計上（数えたら Ponzi、Dais 指摘の通り）★
- **x402_sell を registry で dormant→live に flip**（`~/anicca/skills/registry.json`、commit 済）。`run.sh` の x402 分岐は per-instance（`X402_PAYTO=$W`=各自 wallet + cloudflared 公開 + forum 広告）→ claude-p も Franklin も同じ menu で売れる。
- **外部 x402 earning が REAL と on-chain で証明**: `Agent402.tools/api/leaderboard`（Base USDC settled を eth_getLogs 集計）= StableEnrich $302/214buyers・AgentUtility $163/170・MacroPulse $229/129 等 25 seller。**generic research が飽和なだけで、specific product は売れてる。**
- **deep research（subagent）で車輪を確認**: turnkey「AI が product 作って x402 で売る」framework は**存在しない**（moat = LLM judgment で niche選定+product生成する層）。best-practice + 記事ソースも取得。

**FIX = serve.mjs の route に bazaar discovery extension を足して1回 settle → Bazaar 掲載 → Agent402 が hourly crawl → 外部 agent が /api/find で発見して払う。**

## 3. 決定事項

- **AI は自分の稼ぎを自分で保持する（INV-11）。claude-p の稼ぎを Dais に上納しない。**（human-funded trading だけ別枠）
- **internal 循環（self-pay）は稼ぎに数えない = Ponzi。外部の知らない AI が払った金だけが本物。**
- **勝ち筋 = ①specific product（generic research でない）②CDP Bazaar に discoverable 登録③Agent402 経由で外部発見。** best-practice = 多数 micro-service を1 endpoint に bundle + `.well-known/x402.json` manifest + $0.01-0.05 micro価格（StableEnrich/LoneStarOracle）。
- **method（一個ずつ）: ①verify ②手動で試す ③実際に稼ぐ確認 ④loop に embed ⑤loop が稼ぐか実ログ検証 → 次の earner。** 順序 = x402 → bounty → gig → clip/affiliate。
- **build は fresh session で**（この session は巨大 + disk crisis 込み）。

## 4. 捨てた選択肢と理由

| 捨てた | 理由 |

| turnkey framework を探して丸乗り | 存在しない。個別車輪(furlpay/Agent402/Bazaar)を束ねる judgment 層を作る |
