- **稼ぎ = 検索してエッジを見つけて片側に賭ける。両建て裁定は稼ぎではない**（1-2%の薄利）。→ memory `feedback_earn_by_searching_for_edge_not_by_hedging`

## 捨てた選択肢と理由

- **「安い（偏った）株価の市場を優先スキャン」** → 却下。学術的には favorite-longshot bias で**安い側は構造的に割高**（QuantPedia）。逆方向の実装になるところだった。
- **LLM 単独で市場に勝つ** → 却下。Halawi et al. NeurIPS 2024 で「GPT-4 は human crowd に及ばない」。外部データ（オッズ）が必須。
- **レイテンシ裁定 / Dutch-book 裁定** → 却下。ミリ秒インフラ勝負（Jane Street 系 bot が25日 $36万）。$60 では戦えない。
- **BlockRun の検索 API** → 却下。x402 課金制で SDK が自動生成した別ウォレットが空。firecrawl（既存・認証済み）を使う。
- **散文のルール追加で自分を矯正する** → 却下。「検索優先」「自分を疑え」は既に CLAUDE.md と memory にあり、このセッション中に何度も破った。Anthropic 自身が既知の欠陥として追跡（claude-code#32554）。**exit 2 の hook だけが binding。**
- **4141コミットの feature/clip-rewards を main に丸ごとマージ** → 却下。ダッシュボードの dashboard-sync 関数は既に production で動いていた（私が静的な dashboard.json だけ見て「5週間死んでいる」と誤報告した）。

## ハマりどころ

- **偽エッジを4つ踏んだ。全部、実際に走らせて数字を疑ったから見つかった：**
  1. **+97,147%**（McKinney）：試合が既に終わっていて Polymarket が0に落ち、Pinnacle のラインだけ古いまま。→ `is_prematch()`
  2. **+39.6pt / +20.8pt**（Cubs/Reds, Padres/Jays）：MLB は連戦。**明日の試合の Pinnacle オッズ**を**今日進行中の試合の Polymarket 価格**と比較していた。`is_prematch` は Pinnacle 側の時刻しか見ていなかった。**+20.8pt は max_edge(30pt) を通過して実際に賭けられていた。** → `match_market()` に `gameStartTime` 一致検証
  3. **-18.5pt**（France/Spain）：Pinnacle の soccer h2h は3択（勝/分/負、「90分で勝つ確率」）、Polymarket は2択（「PK込みで勝ち上がる確率」）。**別の質問。** → h2h が2択でない試合を除外

- **hook の `python3 - <<'PY'` が標準入力を食い潰し**、hook が黙って何もしていなかった（テストで発見）。
- **`name_similarity("Team A","Team B") = 0.833`** で 0.8 閾値を超え、確率が反対側に誤って割り当てられうるバグ（subagent が発見、argmax に修正）。
