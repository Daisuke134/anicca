## ハマりどころ
- 公開Base RPC(mainnet.base.org)が urllib デフォルトUAを **403**。`User-Agent: Mozilla/5.0` ヘッダで解決。
- IG reel が occluded タブで再生されない（currentTime停止）。OS-levelの occlusion で `Page.bringToFront`/`Emulation.setFocusEmulationEnabled` では解けず → 専用ブラウザの launch flags が唯一の解。
- IG ログイン input は `name=email`/`name=pass`（`username`/`password`でない）、ボタン text=`ログイン`、onetap=`情報を保存`。
- niche reel collect: `/explore/tags/<tag>/` は `/explore/search/keyword/?q=#<tag>` にリダイレクトするが `/p/`リンクは取れる。画像投稿は video無→watch_oneが正しく非カウント。
- metrics: `og:description` meta が likes/comments の最確実ソース（DOMヒューリスティックは誤取得）。
- vcsdd-adversary は環境により Bash が無く hand-trace のみのことがある（live RPC test は実行不可）。その場合は自分で実走確認する。

## 学び
- **no-mock LIVE E2E でしか出ないバグがある**（occlusion再生停止）。DRY/disk-adversaryでは絶対catчできない → HARD 0.31 の価値。
- **占有ブラウザ/動画自動化の定石** = 2nd stealth-Chromium を別port+profile+anti-occlusionフラグで起動（memory `reference_dedicated_antithrottle_browser_for_video_playback` に記録）。
- adversary は「偽の金を記録できないか」を執拗に攻める → 帰属（誰からの送金か）まで詰めないと misattribution が残る。
- claude-p core の durable cron は disk(scheduled_tasks.json)でなく **セッション内メモリ** に住む（clip と同じ）。Mac再起動で消える＝再起動耐性は別途 OpenClaw cron/jobs.json が必要（未対応・任意）。
