## 捨てた選択肢と理由
- **node 脳（inference.mjs が claude -p を JSON oracle として spawn）**: SyntaxError で死んでいた + project dir ロードで 2 分ハング + 脆い。clip の SHELL 方式が proven（実稼働中）なので廃止
- **skill 毎の判断 loop（clip-core, gig-core, …を並列に立てる）**: 中央の脳が無いと不採算でも盲目に回り続ける（a3cdd4 の hl_trade 空回りが実例）+ N 倍コスト + 「どの変更が収益を動かしたか」評価不能。→ 1 脳が menu から選ぶ + routine は cron
- **fiat/Stripe/銀行 payout を PoE に含める**: AI は KYC（人間クレデンシャル）無しで銀行口座を作れない = no-human-loop 違反。crypto self-custody だけが完全自律レール
- **私（対話セッション）が /loop で稼ぐ**: /loop は監視専用。稼ぐのは独立したヘッドレス claude-p（Dais 明言）
- **USDC 限定の eval**: any chain（SOL/ETH/任意トークン）を USD 換算に一般化（Dais 指示）
- **dashboard と eval を 2 ページに分ける**: eval がランク層そのものなので 1 ページ融合
- **BountyBook**: inline/Lighthouse/Pinata 全て revert で unworkable 確定（以前のセッションから継続）
