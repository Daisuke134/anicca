## 4. ハマりどころ

- **resource URL の http/https**: TLS 終端 proxy(funnel/cloudflared)の裏で Express は `req.protocol=http`。`config.resource` を明示 https でハードコードしないと Bazaar に載らない。★これが「discoverable でも載らない」の真因★。
- **settle と list は別**: CDP facilitator で settle しても、上記 resource が壊れてると index されない。
- **disk 100% で session brick**: colima/claudevm VM の image 肥大（稼働中は rm しても解放されない）。復旧 = VM を stop→delete。**次 session 冒頭で `df -h /`**。
- **subagent は search には最高、implement には使わない**（Dais 方針）。今回 subagent-for-search が真因を割った。

## 5. 学び

- **「search more」は毎回正しかった**。「外部で稼げない」と何度も結論しかけたが、掘るたびに前提が崩れた（飽和→specific なら売れる→leaderboard で on-chain 証明→登録機構 declareDiscoveryExtension→真因は http resource）。断定の前に掘る。
- **earn の本当の課題 = 差別化された needs（agents が実際に買う物）+ 発見(discovery)**。mechanism/rail/listing が完璧でも、agents が欲しい物でなければ $0。
- honest 現状: **colony 外部稼ぎ ≈ $0.027 総額。x402 外部売上 = ゼロ（discovery を今 unblock した。外部 buyer 待ち）。盛らない。**
