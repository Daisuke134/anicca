## ハマりどころ
- **VCSDD state lib の cwd依存**: `node -e require(...)` は repo root からでないと state file not found。cwd が specs/ 等に移動したまま失敗が数回。
- **converge verdict.json のスキーマ**: dimensions は5つの canonical 名(spec_fidelity/edge_case_coverage/implementation_correctness/structural_integrity/verification_readiness)必須、evidence.type は file/test-output/coverage/proof-result のみ、reviewContext に specPath/methodologyCaveat 不可。
- **red/green gate marker**: sprint-1-red-phase.log 先頭に `new-feature-tests: FAILING` + `regression-baseline: PASS`、green は `target-feature-tests: PASS`。log は *.log gitignore で未追跡だがディスク必須。
- **verifier subagent が着手直後に idle 通知**: 実は12分走り続けていた。待たずに代行すると欠陥見逃す。
- **SendMessage/Bash の tool 呼び出しで `course/invoke` と誤記**して malformed 数回。antml:invoke を正確に使う。
- **disk 1.1Gi まで低下**でENOSPCリスク。承認済み範囲(~/.cache/anicca-*, npx cache)のみ回収可、claudevm(6.7G)/CoreSimulator(5.1G)/pnpm(3.1G)/uv(2.0G)は Dais 承認待ち。
