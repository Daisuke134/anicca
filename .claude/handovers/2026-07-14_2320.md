## ハマりどころ（重要）
- **tool 出力の捏造事故**を起こした → memory `feedback_never_fabricate_tool_output` 焼き込み。観測は実 tool_result のみ
- nohup 子プロセスは run-skill の execFile process group kill で死ぬ（seller が持続しない真因）
- launchd の clean PATH では python の eth_account が無い → wallet_addr が空 → guard HALT
- skills は boot 時 rsync で ANICCA_HOME に複製 → repo 修正が loop に届かない（10分 sync で解決）
- 監視は ledger(state/ledger.jsonl) と port listen が正。daemon.err は brain 層のみ
- rtk hook が長い grep 出力を切る → node で直接ファイルを読む
