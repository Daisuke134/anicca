### T13. tool call を MCP に置き換える 🔥 **最初にこれ**

**なぜ**: 我々は tool-call のエンベロープをプロンプトに手書きして自前パースした。
**それは車輪の再発明** — `claude -p` には `--mcp-config` / `--strict-mcp-config` が実在し
（`claude --help` で確認）、**我々自身が `blockrun-mcp` を作って持っている**。

**やりかけ**: `runtime/loop/mcp-decide.mjs`（commit f7a27a35）を書いた。
`run_skill(slot: enum)` と `sleep()` を Zod schema 付きで registerTool（blockrun-mcp と同じパターン）。

**★ブロッカー★**: `@modelcontextprotocol/sdk` が **dist/ 無しでインストールされる**
（`runtime/node_modules/@modelcontextprotocol/sdk/` に package.json と README しか入らない）。
→ `Cannot find module '.../dist/esm/server/mcp.js'`。**ここから始めること。**

**設計上の急所（drop-in ではない理由）**:
`--dangerously-skip-permissions` 下では claude は tool を**選ぶだけでなく実行する**。
だがループの設計は **decide-here / execute-there**（wallet・spend cap・ledger を持つのはループ自身の JS）。
→ **MCP の handler は何もしてはいけない。決定をファイルに書いて返すだけ。** ループがそれを読んで、
自分の条件で実行する。これは既に mcp-decide.mjs にそう実装してある。

**完了条件**: `claude -p --mcp-config` を実行すると決定ファイルが書かれ、brain.mjs の
手書きエンベロープ（`brain.mjs` の `shapeSpec`）が**丸ごと削除できる**。
