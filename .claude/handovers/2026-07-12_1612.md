## 捨てた選択肢と理由
- **timeout を 20分→55分に延長**: 対症療法。sutando を読んで「timeout そのものが誤り」と判明 → 完全削除
- **Reddit の URL を new.reddit に変える**: 無意味。old/new は同じ Reddit の別スキンで、真因は karma=1 の shadow filter
- **X の auth_token cookie を CDP 注入**: 実行したが復活せず（ct0 CSRF も必要 or トークン失効）。認証情報が `.env` にも `~/.cloak` にも無い
- **note の submit ボタンを force-enable**: 空フォーム送信になるだけ。禁止

## ハマりどころ
- **tmux の `session_activity` は「死んでる」判定に使えない** — 全ループ（確実に動いている gig も）で `created == activity` だった。人がキーボードを触った時しか更新されない。生死判定には `.last-pass` marker とログを見る
- **`claude -p` は完了までバッファする** → 途中経過が見えない。監視は成果物（gcal/ledger/API）で行う
- **`curl` の HTTP 200 は公開の証拠にならない** — Zenn は SPA 外殻で 200 を返すが中身は 404。**実ブラウザで見て初めて真実が分かる**
- **article loop の1回目**: 仕事をバックグラウンド subagent に丸投げし、print mode が 600秒上限で打ち切って **rc=0（緑）なのに記事0本**。→ `CLAUDE_CODE_PRINT_BG_WAIT_CEILING_MS=0` + プロンプトに「お前が作業者だ、丸投げして返るな」
- **私が台帳のパスを見間違えて「契約違反」と誤報告した** — 台帳は正しく書かれていた。パスを確認してから断定する
- **subagent が 214k トークン・35分使って何も達成せず終了**（note fix）。報告を待たず自分で実態確認すべき
