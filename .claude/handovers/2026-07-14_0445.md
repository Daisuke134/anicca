### B. 単一インスタンス（overlap 撲滅）
- **真因**: `gig_single_instance.sh` の timestamp lock が check-then-write の **TOCTOU race** → 16個の driver が同時走行（ENOSPC の一因）。
- **修正**: `mkdir` 原子ロック（macOS に flock は無い ← 罠を踏んだ。SO/Baeldung 裏取り: 原子的単一アクション必須、mkdir が macOS の正解）。実証: 2本同時→1本のみ。

### C. ★ディスク brick 事故 → source で恒久修正（4層）★
- **事故**: driver が毎パス6個の claude sub-agent を spawn → transcript が GB 単位で `~/.claude/projects` に溜まり ENOSPC brick（0GB、ツール出力すら書けず）。Chromium は生存・ログイン維持で最悪回避。
- **恒久 fix（Claude Code 公式 docs 引用）**:
  1. driver の全 sub-call に `--no-session-persistence` + `CLAUDE_CODE_SKIP_PROMPT_HISTORY=1` = ★transcript を書かない（ゴミ源を断つ）★
  2. `~/.claude/settings.json` に `env.CLAUDE_CODE_SKIP_PROMPT_HISTORY=1`（全 claude 既定）+ `cleanupPeriodDays: 3`
  3. `emergency-disk-guard.sh`（毎分）: 閾値 4→6GB、`~/.claude/projects` の jsonl >60分を刈る、Chromium cache 刈る、free<3GB で gig sub-agent kill（Chromium が死ぬ前に）
  4. `disk-cleaner.sh`（5分）: free<20GB 予防運転

## 決定事項
- gig の scale = **1 KYC アカウント(mtdc)内で件数を増やす**（marketplace だから。affiliate/clip はモノ毎に新アカウント）。
- 改善原理 = **evaluator-optimizer / Reflexion**（自己診断でなく、勝者を imitation + 外部 evaluator が測定 + 言語 reflection）。agent は自分の問題を診断できない。
- cold-start は A(応募)+モニター価格で初レビューを取り B(出品)フライホイールに点火 → レビュー→ランク→検索上位→inbound→複利。

## 捨てた選択肢と理由
- **flock**: macOS に無い（command not found で driver 全滅）→ mkdir 原子ロック。
- **timestamp lock**: TOCTOU race で16暴走 → mkdir（原子的）。
- **20KB モノリス agent**: step を飛ばす → prompt-chain driver。
- **自己診断（自分の問題を検索）**: agent にメタ認知は無い → 純粋 best-practice検索+scout。
- **binary weak/strong 戦略**: モード切替でなく連続的な問題駆動検索（後にこれも自己診断として廃止）。
- **「掃除を速くする」**: イタチごっこ → transcript を source で書かない。
- **handover して transcript refactor を fresh session で**: Dais が明確に却下（「finish this shit first」）。

## ハマりどころ / 学び
- **state/ledger の掃除で行を落とすな**。バックアップ→in-place 修正→件数検証。`except: continue` が applied.jsonl を破壊した。
- **~/anicca の編集は即 commit**。self-update(git merge --ff-only)が未commitを巻き戻す。編集+commit を1コマンドに。
- **grep guard の誤判定**: `new[:30] in t` が old の接頭辞と一致して SystemExit → 編集されず。ユニークな文字列で guard する。
- **問題が起きたら fix より先に検索**（memory: `feedback_on_problem_search_bestpractice_before_fixing`）。今回 flock/mkdir/prompt-chain/disk 全部 Bible(Anthropic/SO/Baeldung/公式docs)で裏取りしてから直した。
- macOS ≠ Linux（flock 無い）。移植性を確認する。
