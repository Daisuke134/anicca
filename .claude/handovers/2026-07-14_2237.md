## 決定事項
- 投稿方式 = **instagrapi + sessionid**（web composer 廃止、Graph API は将来オプション、必須でない）。
- affiliate = **Digistore24(fiat→Dais 銀行)** + **GMX referral(crypto→AI wallet, agora, INV-11)** の2 rail。
- **1 共有 affiliate account + 多 link + sid1-5 で 200アカ属性分解**（gig の共有KYC型と同じ）。同 niche=共有 offer 再利用、別 niche=finder。account 数でなく offer/channel 数で scale。
- affiliate-finder は **skill**（hardcode 禁止、model が offer/network/account 判断）。account作+finder の2 skill(#15)。shared-first / finder-hedge。
- self-improve = cold-start は勝者 imitate(守破離、hook 最重要40-50%)、traction(自平均×3 outlier)後に自metrics で内部最適化。offer は EPC>commission% で選定・低EPC swap。

## 捨てた選択肢と理由
- web composer 自動投稿 → 構造的デッドエンド（silent reject）。instagrapi へ。
- Graph API 直 → Business化+FB Page+審査2-4週。instagrapi(無料・即)が先。
- CEX crypto affiliate(Binance/Coinbase/Bybit)→ 全部 KYC+取引所口座着地で wallet 直接不可。**GMX referral(wallet接続のみ、on-chain)** 一択。
- ClickBank で作り直す → Digistore が結局 login 成功してた(marketplace 認証済)ので不要。
- affiliate-finder を毎回走らせる → 共有 offer 再利用で token 節約、finder は adaptation 用のみ。
