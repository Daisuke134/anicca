**Date:** 2026-11-04 (JST)
**Decision status:** Research benchmark and implementation recommendation, **not production authorization or a new operational source of truth**.
**Scope:** Manager "What-if × Executor", P05-1→P05-2, synthetic examples. Production owner remains `docs/superpowers/specs/2026-09-25-life-manager-unified-ssot.md`. Curriculum owner remains `docs/research/manager/masterclass/2026-11-04-p04-causal/ROADMAP_STATUS_JA.md`.

## 1. Outcome first

Need a common way to ask:

1. What was observed about subject/context, by whom, **known when**?
2. What goal, intervention hypothesis, alternative and `NO_ACTION` were considered?
3. Which exact action/effect was authorized, attempted, acknowledged and independently measured?
4. What can be inferred, and what is still unknown?
5. Can the state as it was known at decision time be reconstructed without hindsight?
6. Is the graph/query engine measurably better than a simple index for this task?

**Non-goal:** Replacing Manager Core, promoting graph relations to permission, building an extra financial ledger, operating a live personal digital twin, silently extracting health data, or claiming a causal treatment effect from a provider receipt.

## 3. Research contract: four read-only query implementations

All use exactly the same generator `synthetic_events(n_subjects)`, immutable `EvidenceEdge` records from `experiments/p05_1_ontology_readonly.py`, the same as-of query shape `Question(name,subject,cutoff,world_time)` and an **independent synthetic oracle**:

- **FlatScan**: scan all events per query (zero index and higher ongoing CPU).
- **DictIndex**: simple Python `dict[(node_id,predicate)]` indexes.
- **SQLiteIndex**: in-memory SQLite with index for `(source,predicate,time)` and `(target,predicate,time)`.
- **GraphProjection**: P05-1's validated time-aware read-only graph, plus adjacency dictionaries. **This is not the Graphiti library.**

Questions: `goal`, `observations`, `proposals`, `receipts`, `readbacks`, `trace`, `authority`, `causal_effect`.

Every backend returns `NO_AUTHORITY` or `NO_CAUSAL_PROOF` for permission/effect questions, which must only be answered by authoritative services/causal study designs. Graph and dictionary are fixed snapshot projections; a new cutoff requires explicit rebuild rather than hidden time travel.

## 4. Actual measurements (2026-11-04; one Mac, single-process, Python3.14)

Test sizes: **491, 2,451, 12,252 synthetic events** representing 100, 500, 2,500 fictional subjects; **800 queries at each size**, deterministic oracle verified every method, **0 discrepancies**. Each table records medians over the 800 query calls; **building the index is separate**. These are in-memory exact ID queries, NOT human-model prediction and NOT Graphiti full runtime.

| Method | Build ms @12,252 | Query median µs @12,252 | Query p95 µs | 800-query total ms |
|---|---:|---:|---:|---:|
| FlatScan | 0.021 | 6322.292 | 6911.625 | 4210.492 |
| DictIndex | 10.333 | 0.500 | 1.625 | 0.470 |
| SQLiteIndex | 32.497 | 3.292 | 6.833 | 2.437 |
| GraphProjection | 25.335 | 0.500 | 1.750 | 0.477 |

**Decision: use an indexed projection (plain Python dict or existing SQLite), NOT a new graph database.** Graph Projection did **not** provide material benefit over DictIndex in the tested queries. This does **not** establish that Graphiti is slow; Graphiti's time-aware ingestion, entity resolution, semantic retrieval and concurrent update scenarios were not benchmarked.

Raw code: `experiments/p05_1_four_way_benchmark.py`; raw numbers: `evidence/P05-1_QUERY_BENCHMARK_SYNTHETIC.json`; 23 unit tests: `test_p05_1_four_way_benchmark.py`. Benchmark does not include RSS memory, concurrency, warm caches across processes, real-life result accuracy, embeddings or LLM extraction: these must be measured before architecture is generalized.

## 6. Library and model governance

**Commercial use is not equivalent to selling this software directly.** Marketing a product, generating revenue, running a company service or embedding software in commercial workflows can invoke license restrictions even when a model/API is free. Distinguish open-source **code**, open-weights **model**, datasets and hosted-service terms.

- MIT (EDSL): preserve copyright notices and license.
- Apache-2.0 (Graphiti, Palantir Foundry SDK, OASIS): preserve notices/license and review dependencies.
- CC BY 4.0 (BCIO): attribution and applicable rights for imported ontology content.
- AGPLv3 (MiroFish): modification and remote-network interaction may bring network source availability obligations; evaluate with counsel before production integration.
- Listen Labs API: organization key, participant consent, commercial terms, data retention/costs, response rights.
- Model weights: independently check their license, redistribution and model-output terms; do not assume a repo's MIT license applies to a downloaded model.
- Real mental/health measurements, covert personalization and user interventions require appropriate informed authorization and privacy boundaries. "No user in the loop" may mean *no repeated approvals for already scoped low-risk operations*, not bypassing initial consent or provider credentials.

**Identity joins: distinguished keys are mandatory, not guessed:**

| Relation | Existing source checks | Research status |
|---|---|---|
| Job → Effect | `job.effect_key == effect.idempotency_key`, identical `loop_id` and `effect_class` | Verified synthetic |
| Effect → Receipt | `effect_id`, `run_id`, `loop_id`, `provider`, record time | Verified synthetic |

| RuntimeEvent → Receipt | `provider_receipt_id == receipt.receipt_id` when both available | Verified synthetic |
| Prediction/Decision → job | Existing job's `input_refs` may contain refs; there is no shared mandatory `prediction_id` or `decision_id` across four operational source types | **Unresolved** |
| Experiment → all stages | No shared mandatory `experiment_id` across four source types | **Unresolved** |
| Outcome / causal effect | A Receipt or an `official_readback_ref` string is not an independently verified psychological or business outcome; no RCT links here | **Not proven** |

`StampedRecord` adds only a research-reader `known_at` and source URI. The Job lacks a native `run_id` and its own timestamp; the reader does **not** associate a previously known Job with a particular run before an Effect record gives a validated identity link. Replaying the fixture at 09:00:00/09:00:10/09:04:00 gives safely correlated records 0/2/4, rather than pretending later receipts were already known. `known_at` must have an offset-aware timestamp. Conflicts/foreign tenants/mismatched providers run IDs and receipt IDs fail closed. Source content is hashed and changes post-validation are rejected.

### P06-3 test design and minimum sample

Use **existing Statsmodels 0.15.0** `NormalIndPower.solve_power` with `proportion_effectsize` for 2 independent arms, plus **SciPy** `ttest_ind` and `chisquare` for synthetic A/A and sample-ratio mismatch (SRM). For illustrative control p=.25, treatment p=.28, 2-sided alpha=.05, power=.80, required n is **3,395/arm**; allowing 15% attrition suggests 7,990 total recruits. Four *efficacy* decisions at Bonferroni alpha=.0125 raise n to **4,824/arm**, or 11,352 recruited including attrition. These are **not measured from real Manager participants**; real data and consent/necessary ethics are prerequisites for such a trial.

A/A Monte Carlo (2,400 null replications; 4 correlated peeks) gave naive 11.92% familywise false positives vs Bonferroni 3.79% and single fixed final look 4.79%. This is not an implementation of Statsig mSPRT; for future real sequential monitoring use Statsig/Spotify Confidence's rigorously-tested early stopping rather than rolling a new anytime-valid statistics engine. SRM under 560:440 observed vs 500:500 expected gave chi-square=14.4, p=0.0001478 and blocks the analysis. In a serious safety incident, stop immediately based on policy, separate from efficacy significance.

### P06-4 financial increment and harm guardrails

Synthetic study 30,000 randomized units with one primary metric: `recognized_paid_revenue_after_refunds - payment_fees - fulfillment - refund_processing - acquisition - model_tokens - incremental_operator - complaint_cost`. Cumulative company-wide net income is NOT measured; excludes fixed overhead, tax, future returns and possibly other opportunity costs.

SciPy Welch result: synthetic contribution mean **149.12 JPY per assigned subject (Manager) vs 92.29 JPY control**, increment **+56.84 JPY** (95%CI +36.55 to +77.12). The adverse **complaint/optout rate increases by +0.942pp** (95%CI +0.644 to +1.240pp), failing a predeclared +0.3pp maximum guardrail. **Decision is DO_NOT_SHIP**, even though toy net contribution is positive. Real paid receipts, refund ledger, model cost and real harm outcome are all missing -> null, not zero.

This follows Spotify Confidence's four-fold decision gate: success improvement, non-inferior guardrails, no deterioration and valid experiment quality. No increase in engagement or synthetic cash value is accepted as a clinical or business profit claim.

## 15. P07-2: Predictive cognitive/affective states are not authorized interventions (2026-11-05)

**Research status:** We executed actual human experience-sampling data from openESM/Zenodo (both CC BY4.0), and fit participant-disjoint next-state prediction with scikit-learn. We did **not** read private customer records, collect EEG or thought probes, diagnose anyone, deploy any mental-health product intervention, or verify reduced suffering. This is a data/measurement research adapter, not production architecture promotion.

- **Hoebeke 2022**: 40 genuine community participants, 2102 scheduled source records, 1450 eligible next same-day, adjacent-beep transitions. Predict `brooding[t+1]` from observed prior `brooding/perseverance/negativity/self-criticism/replaying/beep[t]`; exclude `activity` and `att_control` because official coding notes are unclear. 24/8/8 participant-disjoint train/val/test. Validation-chosen Ridge alpha=1 achieved heldout RMSE25.979 vs last-observation baseline 30.804, participant-bootstrap CI for improvement [+1.566,+7.807] with only 8 held-out people.
- **Dejonckheere 2019**: 100 people, 9800 actual records, 6890 eligible same-day adjacent-beep consecutive transitions. Predict `stress[t+1]` with previous stressed/happy/relaxed/sad/angry/beep observations. 60/20/20 participant split. Validation-chosen RF achieved heldout RMSE24.543 vs last-stress 27.302, bootstrap improvement CI [+0.471,+4.439] using 20 held-out people. **There is no direct rumination item in this harmonized TSV: these outcomes must never be mixed or relabeled.**
- **Measurement**: self-reported internal state is noisy; the response is an indicator, not ground truth of a fully observed mental state. Participant baseline differences, nonresponse, prompt effects, trait-vs-state confounding, ecology and data-source licensing must be evaluated. This experiment is NOT a causal trial.
- **Research reuse**: 2026 Zhang & Kool GLM-HMM study in 93 persons suggests inference of task-attention state from repeated perceptual choices, but that official model/data have not been rerun in this branch. A 2025 systematic review covered 555 MW measurement studies. OpenNeuro ds001787, ROAMM ds007629, and BCIT ds004121 offer EEG/probe/eye data for future, subject to file size, license and signal-label assessment.
- **Gate for any real user feature**: distinguish `observations` from `latent state hypotheses` and consent from inference; require appropriately authorized collection/use, calibrated uncertainty, user-defined goals, optional NO_ACTION, independent outcome and harm monitoring. Never trigger a user intervention solely because a model infers a rumination state.
