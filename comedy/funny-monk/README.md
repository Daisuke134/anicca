# 面白い僧侶（Funny Monk）— AI アバター説法コメディ

荘厳な僧侶アバターが、真顔でくだらない説法をするショート動画レーン。
Anicca のメイン YouTube チャンネル（コメディチャンネル）へ **毎日1本**、YouTube Shorts（縦型 9:16、約45秒）で投稿する。

- 開始: 2026-11-17（本人の確定で新設。第1話で prove-once 済み）
- これはコメディ専用レーン。終了済みの真面目な僧侶面（monk.mujo／@anicca_cemetery 等）は再開しない。
- 舞台ルール（`comedy/AGENTS.md`）はライブ舞台用の規則であり、この録画動画レーンには適用しない。

## 形式（固定）

- 僧侶アバター（HeyGen、既存の僧侶アバター素材 × Avatar III）が終始真顔・荘厳に語る。
- 構成: 「本日の説法は『（仏教の言葉）』についてです」→ 日常の小さい執着・失敗の体験談 → 教訓めいた言葉遊びで回収 → 身内・他者への毒のある一言 → 「南無」で締め。
- 笑いは「荘厳さと内容のくだらなさのギャップ」で作る。アバターは笑わない・崩れない。
- 1話 約45秒。台本は1話1ファイル（`epXX-テーマ.md`）。確定稿には冒頭に Canonical 日付を明記する。
- 制作費は既払い枠のみ（HeyGen Creator プランのクレジット／既払い API ウォレット）。新規支払い・自動リロードは禁止。

## 制作手順

1. 台本をこのフォルダに保存し、確定稿にする。
2. HeyGen で既存の僧侶アバター＋日本語音声で生成（縦型 9:16）。
3. 五感検証: 全編を見て音声を実際に聞く（声・話速・間・口パク・無音でないこと）。不合格なら1回だけ作り直す。
4. YouTube コメディチャンネルへ Shorts として投稿し、URL を台帳へ記録する。
