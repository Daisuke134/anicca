# Comedy

AI × 人間のお笑いプロジェクトの正本（Single Source of Truth）。台本、演技ルール、バージョン履歴、引き継ぎ、モデル比較をこのディレクトリで管理する。

## 最優先：舞台での開演と声の応答相手（2026-11-15）

**全ネタはダイスが最初に声を出して始める。AIは合図前に絶対に話さない。ネタ中はダイス以外の観客・司会・スタッフ・通行人の声に演技上の応答をしない。** 本番の前置き、挨拶、ネタ選択の質問、自動開始も禁止。詳細と実行条件は [AGENTS.md](./AGENTS.md) を全員必読。音声による話者の完全識別は技術的に保証できないため、本人の明確な合図・演目の事前選択・マイク運用で誤起動を避ける。

## 全AI・全セッション共通の開始手順
1. **`AGENTS.md` の舞台開演ルールを読む（最優先）。**
2. `HANDOVER.md` を読む。
3. この `README.md` を読む。
4. 演じるネタの現行ファイルを読む。
5. `BENCHMARK.md` の共通評価基準を確認する。
6. GitHub mainの最新版を正とし、過去チャットの記憶で上書きしない。

- **就職説明会・面接「株式会社ちっちゃいグミ本舗」v4:** [job-interview-small-gummy.md](./job-interview-small-gummy.md) — 会社説明会がメイン。社長・開発者・配送員・商品の寸法・給与明細まで具体的だが全て妙。途中で勝手に採用・入社・研修が始まる。グミ詐欺電話とは別ネタ。

## 開演合図（ダイスが先に話す）
- 「グミ」「残高」：演目を舞台前に確定したうえでダイスの「もしもし。」が開演。
- 「痛い痛い！」：ダイスの「痛い！」が開演。
- 「ちっちゃいグミ本舗」：ダイスの「こんにちは。会社説明会に来ました。」が開演。
- **合図前はAIが無言、合図後はダイスの声だけに応答。** 誰が何を言ったか判別できない場合は勝手にネタを始めない。

## 運用
- 1ネタ1ファイルを基本とする。別フォーマットを混同しない。
- 台本には完全稿、演技ルール、展開設計を含める。
- 旧稿は削除しない。Gitのコミット履歴で過去版に戻せるようにする。
- 更新はブランチ→Pull Request→mainへマージ。mainへ直接書き込まない。
- 書き込み、PR、マージ、main再取得を確認するまで「更新済み」と報告しない。

## 目標
人間とAIの2人で世界最高水準のお笑いを作る。ネタを量産するだけでなく、笑いの構造を研究し、舞台での反応を記録し、複数モデルを同一条件で比較して改善する。
