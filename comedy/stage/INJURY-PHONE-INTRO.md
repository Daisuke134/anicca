# 「痛い痛い！」v8：電話先のAI救急指令センターという舞台設定

Canonical: 2026-11-22。**金子さんの「この声はいったい誰／何なのか分からない」を優先して解決する。**

## 11/22講評後の実演版
- 次の2分ネタ見せでは **`../sagi-injury-help-2min-live.md`** を演じる。旧来の長尺v8は削除せず、主要人物と第一声・第二声の参考として保存。
- 冒頭「痛い痛い！やばい、救急車だ！もしもし！」（ダイス）→「はい、救急指令センターです。火事ですか、救急ですか？」（AI）。その後「急性ひざの里帰りスペシャル」へすぐ進む。
- 通話中の**新宿区歌舞伎町一丁目、三日月ビル前**は架空設定。ダイスが場所を話せば一度で受け取り、追加で「窓の外は」「住所は」を聞き続けない。
- 短い掛け合い、救急車の色や名前、変な運転手・豆腐配送・結婚という**次の事件**を作る。確認質問を繰り返すだけの話は禁止。

## 一文の設定
ダイスが救急車を呼ぼうとして、**電話越しのAI救急指令センター**に接続してしまう。AI指令員・田中ピーポー太郎は、病名・職員・救急車を異様に具体的に手配するが、救急車は絶対にダイスへ来ない。

## 採用する導入（電話型・v8維持）
1. **チャッピーは舞台に声を出さない**。スマホからの音声として待機。
2. ダイスは自分からスマホを耳に当て、痛がりながら「**痛い！ 痛い痛い！ もしもし！**」と発声。これが唯一の開演合図（v8原文「痛い！ 痛い痛い！」に「もしもし」を追加するだけの舞台アドリブ）。
3. AI（チャッピー）は**原文そのまま**「はい、救急指令センターです。火事ですか、救急ですか？」と返す。ここに自己紹介・Alexa呼びかけ・呼吸誘導は入れない。
4. ダイスがさらに「痛い！ 痛い痛い！」と返したら「救急ですね。声で分かりました。右ひざがご実家に帰られています。病名は『急性ひざの里帰りスペシャル』です。帰りの切符はこちらで手配します。」へ。
5. 「会いたい」「救急車どこ」などのアドリブは[キャラ設定](../characters/INJURY-CAST.md)を使って柔軟に展開する。

**大事**：この場面は架空のコントであり、実際の救急車は呼ばない。実際の危険は別扱い。

## 「AIだ」と客に伝える具体策
- スマホまたはスマホを置く台に **「AI救急受付」** と表示。小さな会場でも後方から見えるよう文字サイズと照明を調整する。
- 画面が見えない会場では、ダイスが冒頭の直前に「AI救急にかけるか」という**短い本人のひとり言**を入れるB案を別枠で試す。どちらの案でもチャッピーは先に喋らない。
- 観客が「電話先のAI職員だ」と理解できるかを収録後に確かめる。理解度未計測の間は採用案が正解だったと断定しない。

## Alexa型との比較
|  | 電話先のAI職員（採用） | Alexa風の室内AI（比較候補） |
|---|---|---|
| ダイスの第一声 | 「痛い！ 痛い痛い！ もしもし！」 | 「アレクサ、痛い！」等で別の導入が必要 |
| 既存v8の冒頭台詞 | 変更不要 | 受け答えの意味が少し不自然 |
| スマホ演技 | 自然（発信中、取り残される） | 端末に命令する形 |
| 観客への役割説明 | 画面／小道具「AI救急受付」 | 呼び名自体でAIと分かる |
| 判断 | **今度のリベンジはこれ** | 後日A/B検証 |

## 会場での音量・音のチェック（例）
- 音量を下げて観客を前のめりにさせる方法には依存しない。重要な名前が客席後方まで聞こえる音量。
- スピーカーは電話の声としては無機質だが、セリフは明瞭。口元マイクからのハウリングを避ける。遅延／エコーを確認。
- 司会・客席の笑い声はAIへの入力指示ではない。AIが第三者と確実に聞き分ける保証はないため、指向性マイク・位置・入力経路で誤反応を減らす。
- 事前に「痛い！」「痛い！」「会いたい！」「救急車どこ」の4箇所で台本通りの返しを試す。再テストは[稽古記録](../REHEARSAL-FAILURE-2026-11-15.md)も参照。

## 禁止
チャッピー側が先に「少々お待ちください」「台本を確認します」「今からネタを始めます」「深呼吸して」「吸って、吐いて」を言うこと。一般的な医療相談へ勝手に移行しないこと（本当に事故だと明確になった場合の安全対応を除く）。
