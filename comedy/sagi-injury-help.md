# コント「痛い痛い！」v5｜決めつけ救急・誤配車・誤搬送

> Canonical: 2026-11-15。v4から全面改稿。ダイスはほぼ「痛い！」「痛い痛い！」「会いたい！」しか言わない。チャッピーは最初の一問以外、細かく確認しない。勝手に病状を診断し、妙な車両・施設・搬送先を次々に手配して事態を進めるが、肝心の救急車だけは絶対に届かない。

## 配役・演技ルール
- **ダイス**：救急へ電話した通報者。セリフは「痛い！」「痛い痛い！」「会いたい！」を基本とし、痛さに応じて声量や間だけ変える。事情説明や解説ツッコミをしない。
- **チャッピー**：救急指令センターの担当者。最初は仕事が速く、有能そう。以後は一方的に勘違いし、病名、行き先、車、受け入れ先を即決する。基本的に質問しない。細かい確認項目を並べない。真面目に、スピード感を持って、とんでもないことを実行する。
- **2人芝居**：ほかの職員や運転手は登場しない。チャッピーが一人で電話報告や連絡を読み上げる。
- **笑いの軸**：「どんどん手配が進むのに、救急車だけは来ない」。痛みを別の症状と誤認し、「会いたい」は恋愛・面会・式場の手配につながる。
- **安全上の注記**：架空の舞台コント。現実の119番通報や救急医療の手順を示すものではない。

## 演出メモ・即興の芯
1. **質問は冒頭の「火事ですか、救急ですか？」だけ。** 以降のダイスの「痛い」をチャッピーが勝手に診断・決定・実行へ変換する。問い詰めるのではなく、即座に次のボケへ進む。
2. 「痛い」の強さを症状や手配内容に勝手に反映。「会いたい」は面会→出会いの広場→結婚式場→救急車を新郎にする、という暴走のエンジンにする。
3. **変な場所と車は固有名詞で具体化する。** 畳屋、スポーツジム、クリーニング店、市民会館、同窓会場、式場。豆腐配送車、引っ越しトラック、スクールバス、消防車、冷凍車、焼き芋車、観覧車。
4. 呼んだ車や施設のその後を回収する。どんどん進捗している報告があるのに、ダイスのところへ救急車は届かない。
5. ダイスは余計なツッコミをせず、苦しそうに「痛い」、恋しそうに「会いたい」を言うだけで成立する。チャッピーは最後まで全力で有能な職員を演じる。
