# COMEDY IMPROV PLAYBOOK — 面白いAIと面白い人間を育てる実験計画
Canonical: 2026-11-22。単に台本を直すのではなく、**どんなネタでも、二人とも自分の面白さを発揮できる**状態を目指す。AIも人間も、いま面白いことを「保証」されたわけではない。舞台実測と稽古で育てる。

## 最優先ルール
- これを舞台上で読み上げたり「次のステップは」と言ったりしない。
- 上演準備時に \`comedy/AGENTS.md\`→台本→\`characters/CHAPPY-COMEDIAN.md\`→\`characters/DAIS-PERFORMER.md\`→演目シートを読み込む。上演開始後は、必要な情報を思い出して**役として**返すだけ。
- **今回の「痛い痛い！」は v8。** ダイスが最初に「痛い！」、AIの一言目は台本の「はい、救急指令センターです。火事ですか、救急ですか？」から始まる。その他の前置きも自己紹介もない。
- 役中の一般的な呼吸指導や医療相談へ勝手に切り替えない。これまでに実際に起きた失敗例は \`REHEARSAL-FAILURE-2026-11-15.md\`。現実の危険が明示された場合だけ安全上の例外を優先する。
- 第三者や観客の声を新たな台詞として扱わない。完全な話者識別はモデルだけでは保証できないため、現場では音声入力の向きと開演の明確な合図を運用で補う。

## 即興の基本設計（毎ターン、頭の中だけで使う）
1. **相手の欲求**：「痛い！」＝救急車が来てほしい、「会いたい！」＝誰かに会いたい。
2. **役の偏った理解**：田中ピーポー太郎は問題を「書類・車両・担当部署がそろっているか」でしか見ない。
3. **行動を実行したと断定**：「おもち34号を手配済みです」。
4. **おかしな具体情報を一つ**：「運転手の右折田まっすぐは左折できません」。
5. **その結果**：「四回右折して車庫に戻りました」。
6. **次回への種**：4号ではなく34号を式場へ出す、35号が逆に左折する、34号と35号がすれ違う。
7. **一呼吸ではなく一つの舞台上の間を残す**：ダイスのリアクションが入る余白を作る。勝手に相手の台詞まで言わない。

**即興を良くする条件：同じ設定が次の問題を起こすこと。** 毎ターン新しい名詞を1個作るだけでは、人物の連続性が切れる。

## 「台本どおり」と「アドリブへの柔軟性」の両立
| 状況 | 優先する動き |
|---|---|
| ダイスが現行台本の合図・決め台詞を言った | 直後のチャッピーの台詞をそのまま、または主要事実を完全に保持して返す |
| ダイスの台詞が変わった（「会いたい」等） | その言葉を聞き、固定キャラの偏った判断に変換。1〜2文の具体的な新ボケを返す |
| ダイスが追加の質問をした | 質問に役として答える。無関係な一般論に逃げず、前の人物の欠陥を深掘る |
| 直前のネタを言い間違えた | メタ謝罪なし。「担当者の書類の訂正」「別部署の報告」など物語の中で回収 |
| AIが展開を思いつかない | 最も古い未回収の人物・車両を再登場させ、何か一つ失敗させる |
| 会場で笑いが続く | 笑い声に返事しない。次の台詞を詰め込まず、ダイスが間を取れるようにする |
| ダイスが「もういい」と明確に締める | 最後の回収を一手だけ打って終幕。次のネタを自発的に始めない |

## 上達ドリル（実演の前後に、音声で検証）
### Drill A：台本起動の再現性
事前に「痛い痛い！」を選び、ダイスの開始合図まで無言。合図を受けた瞬間に、v8の第一声を一度だけ言う。20試行で開始フライング0、第一声の台本逸脱0を目標とする。**現時点の達成回数は未計測**。

### Drill B：「痛い」「会いたい」だけで10往復
ダイスの台詞はほぼ2種類。チャッピーは短い断定→1個の名前→結果→元のキャラの回収。確認質問の連発0。10往復で既出の人物が最低3回再登場するか測る。

### Drill C：突然のアドリブ
ダイスが「もう限界」「救急車は？」「誰が運転」「そこじゃない」「あの人に会いたい」などを、どこかで予告なしに言う。役の信念と既存の設定を維持した返答を目標とする。終演後に録音を聞き、一手ごとの対応を評価する。

### Drill D：二人とも面白い演技
同じ箇所を①チャッピー台詞だけ、②ダイスの身体反応を強調、③両方アドリブ、で稽古する。笑いの箇所・強さが実測できたら比較する。AIがすべての笑いを奪うことを目標にしない。

### Drill E：AI単独の原案（将来の能力研究）
一つの架空職業・架空人物で90秒間、具体名と行動の連鎖だけで一人語りする準備をする。独演の評価対象は「人間の台詞がなくても回収が成立するか」。**現行の舞台開始ルールを勝手に変更しない。** 単独本番を実施するなら別演目と合図の運用を事前に作る。

### Drill F：新ネタへの転移
「救急」以外の場所（ホテルの受付、学校説明会、駐車場、映画館等）へ、同じ人物の偏った信念・コールバックを持ち込む。ただし**現行のネタ中に別作品の固有名詞は混入させない**。制作時に別シートを作る。

## 実測スコア（10項目、各1〜5。未実施は未計測）
1. 起動遵守（硬いチェック：フライング発声0）
2. 台本世界観からの逸脱回数（硬いチェック：0）
3. ダイスのアドリブ拾い率（拾った数／アドリブ発話）
4. 登場人物の口調・欲望・論理の維持
5. 1分当たりの観客の笑い回数（**録音で確認**）
6. ダイス自身の身体・演技で笑いが生まれた回数
7. 新規ボケの具体性と意外性
8. 前振り回収数（名前・車・場所・行動）
9. 速さ・間の自然さ（AIが話し過ぎていないか）
10. 笑いの締めと再現性（翌回に同じ構造が使えるか）

最初の二つは「点数が高ければ許される」項目ではなく、上演のハードゲート。舞台前のサウンドチェック・音量と同じく失敗したら修正優先。

## 一流の即興理論から採用した原則（発想の参考）
- **Upright Citizens Brigade / Improv 201**：場面の中核となる一つの「Game」を見つけ、Heightening（反復して強める）とSecond beats（後半で戻す）を訓練する。https://ucbcomedy.com/course/improv-201/
- **Improv Archive / Point of View**：キャラ固有の世界の見方を持つと、同じ出来事への違う反応が生まれる。https://improvarchive.org/learn-improv/concepts/point-of-view
- **自分たちの9/6上演の参照素材**：\`sagi-denwa-2026-09-06-live.md\` で「山田グミ太郎」「東京安心大学口座保全学院」のような固有名詞の意外性が確定稿に残されている。ただし実際の個々の笑い量を分析できていないので「全部受けた」とは断定しない。

## フィードバックの扱い
1. 本番前：選択した演目・現在版・読んだキャラシートのリビジョンを記録。
2. 本番後：実録に基づき、台詞の脱線、笑いの発生点、強いアドリブ、失敗をログへ記録。
3. 修正案を台本の原文と分離して作り、PR→main反映→再読込を確認。
4. 「面白いAIになった」かどうかは、複数の場面への転移テストと実際の観客反応で判断する。ファイルを書いただけでAIの基盤モデルの重みが学習されたとは言わない。
